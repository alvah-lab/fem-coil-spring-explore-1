# 温度变化检测通道 Brief（方案C 附加功能，2026-09-07）

前提：读者已知方案C 反射环原理。本文讲如何用同一套测量得到每个单元的**铜环温度变化**，进而估计接触物体与表面交换的热量。目标是 ΔT 与热量，不是绝对温度。**不新增测量，只使用现在丢弃的反射实部，外加一个低频音。**

---

## 1. 原理

反射阻抗 Z_r = ω²M² / (R_t + jωL_t)，Q_t = ωL_t/R_t ≫ 1 时：

| 分量 | 近似 | 依赖 |
|---|---|---|
| 虚部 Im(Z_r) | ω·M²/L_t | 只随位姿（M）变，与 R_t 无关 → 位姿通道 |
| 实部 Re(Z_r) | ω²·M²·R_t/L_t² | 随位姿和铜环电阻变 |
| **比值 Re/Im** | **R_t/(ωL_t) = 1/Q_t** | **M² 抵消，与间隙无关，只随铜环温度变** |

铜温度系数 α = 3.9e-3/K → ΔT_ring = Q_t0 · Δ(Re/Im) / α。同一次自观测同时给出位姿（虚部）和铜环温度（相位角）。

## 2. 铜环作为量热计

| 量 | 值（Ø5/Ø3/0.2 紫铜环，BF-1000 2.38mm） |
|---|---|
| 环热容 C_ring | 22mg × 385 J/kgK ≈ **8.5 mJ/K** |
| 环→PCB 漏热（泡棉 k=0.048 W/mK） | ≈ 0.25 mW/K |
| 漏热时间常数 | ≈ 34 s |
| 1s 内参与的泡棉表层 | 扩散长度 ≈ 0.44mm，≈ +1.2 mJ/K |

接触事件（<5s）内漏热可忽略：**Q ≈ C_eff · ΔT_ring**，C_eff 略大于 8.5mJ/K、随事件时长缓变，用已知热脉冲（恒功率加热探头按压 1s）标定一次。

## 3. 必须分离的干扰：线圈自身电阻

自观测实部 = R_c(线圈) + Re(Z_r)(铜环)。R_c ≈ 1.2Ω，温漂 4.7mΩ/K；铜环项静息仅 ~11mΩ，温漂 44µΩ/K，小 100 倍。分离用**频率**：

- 在 ~100kHz 加一个低频音测同一线圈：反射项按 (8M/100k)² = 6400× 缩小可忽略，趋肤不存在，测得纯 R_c(T_coil)。
- 8MHz 实部 − R_c,ac（R_ac/R_dc 比为固定几何量，标定）= 铜环项。
- 线圈隔着 2.4mm 泡棉，响应比铜环慢 1~2 个量级，本身是第二只温度计（PCB 温度）。
- 原型：100nF 隔直在 100kHz 为 16Ω，标一次相位即可；ASIC：直流偏置电流直接测 R_c。

## 4. 灵敏度

按当前链路每驻留 1e-3 相对噪声、静息自观测反射 1.0Ω（ω·20nH）、铜环 Q≈89：噪声密度 ≈14µΩ/√Hz，信号 44µΩ/K，单线圈连续测 0.32K/√Hz；61 驻留分时后每单元 ×√61。

| 配置 | 单元 ΔT 分辨率（1s 平均） | 能量分辨率 |
|---|---|---|
| v1：10mA，Q_ring 89 | ~2.5 K | ~20 mJ |
| 30mA | ~0.8 K | ~7 mJ |
| 30mA + 铜环 Q 降到 25 | ~0.23 K | ~2 mJ |
| 再加 v2 调零 | ~0.05 K | ~0.4 mJ |

压缩态反射更大（45% 时 5×），分辨率同比提高。参考：手 +10K、热杯 +40K，v1 一秒可见；同温度下金属 vs 塑料看热流速率，需 ~0.2K 档。

## 5. 设计杠杆：铜环 Q 设计到 20~30

实部 ∝ R_t，虚部与 R_t 无关 → 提高环电阻只涨温度信号，不伤位姿。趋肤（8MHz δ=23µm）限制了减薄的效果，有效做法是**冲压时留窄颈**：0.2mm 宽颈每 1mm 长约 +2mΩ，颈总长 5mm → R_t 13mΩ、Q≈27。代价：1/Q² 项使位姿出现 ~14nm/K 温漂，而温度正好被测到，可精确修正。铜环材料保持紫铜（α 高、导热好）；黄铜 α 仅 1.5e-3/K，不用。

## 6. 反演

19 个铜环 R_t 作为未知量，位姿由虚部给定后，用 61 个观测的实部联合拟合（环-环杂化路径已在全矩阵模型内）。温度慢变，按 1s 窗口平均后求解。输出每单元 ΔT_ring、ΔT_coil、Q_热量。

## 7. 连带收益与限制

- 硅胶 CTE ≈2.5e-4/K → 2.38mm 泡棉 0.6µm/K 热胀，与位姿分辨率同量级；有了两只温度计可修正。
- 铜环上方若加保护皮（0.1~0.3mm 硅胶），热响应变慢但仍可测；量热标定需在带皮状态做。
- 时间分辨率由平均窗口定（~1s），不适合毫秒级热事件。

## 8. 验证

1. 静置：记录 60s，Re/Im 比值噪声应与 §4 一致，R_c 通道与 PCB 上热敏电阻同步漂移。
2. 已知热源：Peltier 片贴在一枚铜环上做 ±5K 阶跃，看 ΔT_ring 响应与热电偶对比，确认位姿通道不动（<0.1µm）。
3. 量热：恒功率探头（如 50mW × 1s = 50mJ）按压，回算 Q，标定 C_eff。

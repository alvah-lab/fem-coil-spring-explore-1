# 方案 C 专利分析 Brief（无源反射环式六维力传感阵列）

供专利检索/新颖性分析用。所有性能数据来自 FastHenry 电磁有限元计算（双环互感对 Maxwell 椭圆积分解析解偏差 <0.8%）。

---

## 1. 一句话描述

一种电磁式柔性力/力矩传感阵列：柔性表面内侧嵌入**无源闭合导电环**（随表面运动），刚性基座上排布**有源线圈**（固定，接驱动与检测电路）；驱动某有源线圈时，各无源环因互感感应出涡流并反射回有源线圈，改变其端口有效阻抗；由多个有源线圈端口的阻抗变化联合反演出无源环的位姿场，进而重建表面六维力分布。

**与常规互感式传感器的根本区别：运动敏感层完全无源、无引线、无电子器件。**

---

## 2. 核心权利要求要点（按新颖性强度排序）

### 独立权利要求（装置）
一种力传感阵列，包含：
- 固定基座上的**有源线圈阵列**（每单元连接正弦驱动源与阻抗/相位检测电路）；
- 柔性表面内侧的**无源闭合环阵列**（每单元一个，与对应有源线圈磁耦合，随表面变形改变相对位姿）；
- **其特征在于**：位姿信息通过测量有源线圈端口的**反射阻抗**（无源环涡流回授引起）获得，运动层不含任何有源器件或引出导线。

### 关键从属特征（每条可独立构成新颖点）

| # | 从属特征 | 技术效果 | 新颖性论据 |
|---|---|---|---|
| C1 | 无源环为**单匝**闭合环（冲压/印刷导体） | 反射强度与匝数无关（磁通守恒 M²/L 定标），单匝即最优；成本趋零 | 反直觉：常规设计倾向多匝增耦合 |
| C2 | 有源线圈**参考锚点设至少两种固定高度**（三色格下沉），任一单元邻域含两种高度 | 消除平移/倾斜共模简并，联合反演满秩 | 承自本项目独有的简并判决 |
| C3 | **两级反演**：反射阻抗→无源环位姿场→表面六维力；绕法向扭矩由位姿场旋度阵列级重建 | 单元 5 自由度+阵列 Mz=完整六维 | |
| C4 | 非活动有源线圈保持**开路/高阻**（回路阻抗≥工作频点下的阈值，实施例≥230kΩ） | 消除第三线圈间接耦合串扰（开路 0.02% vs 谐振 10⁴%） | 定量测量协议 |
| C5 | **桥式/调零检测**：以基座固定几何标定的参考音抵消阻抗载波，仅放大反射偏差 | 反射（1.9~5%载波）从相对基准搬到绝对基准，法向灵敏度提升~38倍 | 与无源环载波结构强绑定 |
| C6 | 利用反射阻抗**虚部**（∝1/Q²温度免疫）测位姿、**实部**测温度补偿 | 高Q时免温补；实部兼作分布式温度计与断环检测 | |
| C7 | **观测局部化**：每观测仅纳入相关单元一圈邻居的无源环（单-双 pitch 截断） | 反演矩阵带状稀疏，算力从 O(N³) 降为局部块，大阵列可扩展 | 自观测截断误差<0.4% |
| C8 | 有源线圈为**多股细线捆束单环**（束径<环径1/10），无源环为单匝 | 有源侧匝数×位姿信息经反射；上下层匝数非对称 | |

## 3. 与三类最接近现有技术的区分

| 现有技术类别 | 代表原理 | 方案C的区别 |
|---|---|---|
| **涡流位移/接近传感器** | 单个有源线圈探测导体靶标距离，测自感变化 | 本方案是**阵列+多端口互耦反演六维**，靶标是结构化环阵而非平板；有共模破简并结构 |
| **无源LC遥测传感器**（植入式压力等） | 无源LC谐振腔，外部线圈测其谐振频移 | 本方案环为**短路非谐振**（无电容）、**阵列化**、测反射阻抗而非单腔谐振；无源环不需精密电容 |
| **互感式触觉阵列** | 上下层均有源线圈测互感 | 本方案**运动层无源无引线**（可靠性核心优势）；交错锚点破简并；反射体制 |

**检索建议 CPC/IPC**：G01L1/12, G01L5/16, G01L5/226（力/力矩）；G01B7/00, G01D5/20（电感/涡流位移）；G01L9/00（无源遥测）；A61B5/00 与 G06F3/041（触觉/柔性传感）。关键词组合："eddy current" + "array" + "six-axis/6-DOF"；"passive coil" + "reflected impedance" + "tactile"；"shorted loop" + "force sensor"。

## 4. 关键性能数据（19单元实施例，可作效果证据）

- 结构：有源线圈 Ø5mm/15股捆束单环，无源环 Ø5mm 单匝短路铜环（Q≈28@2.5MHz），pitch 5.2mm，交错锚点下沉0.9mm；
- 可解性：柔性表面先验下 61观测×57未知**满秩、无结构盲区**，强子空间条件数9.3（优于双端口独立方案的11.3）；
- 分辨率（调零后，1e-3反射测量精度）：法向 0.8µm、面内差分 3.1µm；
- 温漂：1.9×10⁻⁴/K（虚部1/Q²免疫，实测确认）；
- 尺度不变性：等比缩放至1mm，可分性/信号强度几乎无损（反射绝对量守恒），仅无源环Q下降（28→3.2，可经提频+扁平导体恢复至~15-20）；
- 反演：强54方向阻尼牛顿+弱3共模方向慢通道；观测局部化后大阵列算力线性可扩展。

## 5. 潜在规避设计需一并覆盖（防竞品绕行）

- 无源环用**开口环+集总电容**（弱谐振）替代短路环 → C1/独权应涵盖"闭合或经无源元件首尾相连的环"；
- 参考高度差用**倾斜锚点**而非下沉高度实现 → C2应上位为"锚点相对无源环的等效接收高度存在至少两种"；
- 反射测量用**频率法**（测谐振/相位频移）而非阻抗法 → C3/独权检测手段应涵盖幅度、相位、频率任一；
- 阵列排布用正方格而非蜂窝 → 权利要求勿限定六边形。

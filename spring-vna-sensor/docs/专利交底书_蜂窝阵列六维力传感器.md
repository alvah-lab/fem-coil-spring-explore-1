# 专利技术交底书

## 发明名称（建议）

基于交错锚点高度蜂窝线圈阵列的电磁式柔性六维力/力矩传感器及其检测方法

---

## 一、技术领域

本发明涉及柔性触觉传感与力测量技术领域，具体涉及一种通过测量线圈间互感变化来重建接触表面六维力/力矩分布的电磁感应式传感器阵列，及其配套的信号检测与反演方法。

---

## 二、背景技术及其缺陷

现有柔性触觉/力传感器主要包括：

1. **压阻/压电式阵列**：只能测量法向压力分布，无法获得切向力（剪切）与力矩信息；且敏感材料存在蠕变、迟滞。
2. **电容式三维力单元**：可测三维力，但电极间距小、易受湿度与寄生电容干扰，切向量程小，难以扩展到六维。
3. **视觉/光学式（如凝胶+相机）**：可获六维信息但体积大、帧率与鲁棒性受限，不适合薄型大面积表面。
4. **单线圈电感式传感器**：利用线圈变形引起的自感/谐振频率变化测压缩。发明人的前期有限元研究证明其存在**原理性缺陷**：对称线圈的标量观测量对方向性变形（弯曲、剪切、扭转）仅有二阶响应，且压缩与弯曲在 (L, C) 观测平面上近似共线（可分性条件数达 896），无法分离多维载荷。

进一步地，即使采用"驱动一个线圈、测量相邻线圈互感"的阵列方案，发明人通过有限元计算发现仍存在两个未被现有技术解决的问题：

- **共模简并问题**：当所有参考（锚点）线圈位于同一高度平面时，被测线圈的"整体平移"与"整体倾斜"两种变形在锚点层产生**同形的余弦方位角图案**，二者在数学上简并（联合灵敏度矩阵出现多个近零奇异值），导致切向共模力与共模弯矩不可分离；
- **串扰问题**：非活动线圈若带有低阻抗或谐振负载，会形成"驱动线圈→第三线圈→接收线圈"的间接耦合路径，对弱耦合观测量的污染可达 150% 以上，使测量失真。

因此，需要一种既能提供六维力信息、又从结构上消除共模简并、并规定了抗串扰测量协议的电磁式传感阵列。

---

## 三、发明内容

### 3.1 要解决的技术问题

1. 单点/单线圈传感器无法分离六维力分量的问题；
2. 同高度锚点阵列中共模平移与共模倾斜的简并（不可观测）问题；
3. 阵列中非活动线圈负载导致的间接耦合串扰问题；
4. 表面弹性连续导致的多单元机械联动（一点受力、多单元变形）下的载荷重建问题。

### 3.2 技术方案（核心）

#### （1）传感单元结构

每个传感单元包含：

- **表层线圈**：束绕圆环线圈，由 N 股细漆包线（实施例：15 股 × Ø0.05mm）捆成一束绕制成中径 D（实施例：Ø5mm）的圆环，束径远小于环径（约 0.22mm），环面近似无高度；固定于柔性表面内侧，随表面运动；
- **锚点线圈**：与表层线圈同规格的束绕圆环，固定于刚性基座，作为**位置已知的绝对参考**；
- **弹性支承**：连接表层与基座的弹簧（实施例：非闭合回路的漆包线弹簧，两端开路，电磁近似透明），允许表层线圈相对锚点线圈发生压缩、平移（剪切）与倾斜；表层-锚点线圈法向间距在工作行程内变化（实施例：1.0–2.5mm）。

#### （2）蜂窝阵列与交错锚点高度（本发明的第一个关键特征）

多个传感单元以六边形（蜂窝）密排布置（实施例：中心距 5.2mm）。**锚点线圈不设于同一高度平面，而是按阵列的着色规则设置至少两种嵌装深度**：

- 将三角格阵列按三色规则着色，取其中一色（约 1/3 单元）的锚点线圈下沉深度 d 嵌入基座凹槽（实施例：d = 0.9mm），其余保持基准高度；
- 该布置保证**任一单元的"自身+六个相邻"锚点集合中必然同时包含两种高度**；
- 下沉凹槽位于刚性基座一侧，不占用弹簧压缩行程、不与任何活动件干涉。

**破简并机理**（发明构思的核心）：表层线圈的平移与倾斜作为磁偶极子的"位置移动"与"方向转动"，在同一接收高度的锚点环上产生同形 cosφ 图案，仅系数不同——一圈同高度锚点等价于只提供一个标量方程，二元（平移、倾斜）不可解。而该系数之比随接收高度变化，故**两个接收高度提供两个线性无关方程**，平移与倾斜即可解耦。有限元验证：下沉 0.9mm 使共模简并模式的可观测度（奇异值）提升约 74 倍；19 单元阵列的联合灵敏度矩阵（145 观测 × 95 位姿未知量）满秩、无任何规范（不可观测）模式，条件数 55。下沉深度存在最优区间（实施例 0.8–1.0mm）：过浅则两高度系数比差异不足，过深则下沉层耦合信噪比衰减，约 1.2mm 后收益饱和。

#### （3）测量拓扑与抗串扰协议（第二个关键特征）

- 每个线圈连接至可选通的正弦驱动源与相干（IQ）幅相检测电路；
- 测量时驱动某一表层线圈，检测其与自身锚点线圈、六个相邻单元表层线圈及六个相邻单元锚点线圈之间的互感（每单元 13 路观测）；
- **非活动线圈必须呈开路/高阻状态**（实施例：≥100kΩ）；禁止低阻抗端接与串联谐振负载。有限元-电路联合计算表明：50Ω 端接对最弱观测量的间接耦合污染达 151%，串联谐振负载达 10⁴% 量级，而开路时仅 0.02%；
- 可选频分复用：按上述三色规则，同色单元使用不同驱动频点同时激励，使整帧采集时间与阵列规模无关。

#### （4）两级反演方法（第三个关键特征）

- **第一级（电磁反演）**：以全部互感观测为输入，**联合估计所有表层线圈的位姿场**（每单元 5 自由度：三平移+两倾斜；绕环轴的旋转因线圈旋转对称在单元级无电磁签名）。锚点线圈全部固定这一结构使"表层→锚点"类观测只依赖单个单元自身位姿（联合灵敏度矩阵呈块对角主结构），联动变形不破坏可观测性，只需在各单元各自的工作点线性化；
- **第二级（力学反演）**：位姿场经标定的弹性面刚度/柔度矩阵映射为表面六维力/力矩分布；绕法向的扭矩分量 Mz 由多单元切向位移场的旋度在阵列级重建。

有限元端到端验证（19 单元、含"中心点压+邻居联动+共模剪切+共模倾斜"复合真值）：位姿场恢复误差——压深 0.5µm 级、共模剪切 150.4µm/真值 150µm、共模倾斜 1.998°/真值 2°；在千分之一互感测量噪声下分辨率为法向 0.9µm、切向 4.5µm、倾角 1.7 角分。

#### （5）半端口数变体（从属方案）

上下两线圈**按互感增强方向串联**构成单端口，端口数减半（19 单元：38→19）。此时端口自感 L=L_T+L_B+2M 对压缩一阶敏感、邻边观测为四项互感之和。该变体在"表层为弹性连续表面（倾斜=表面高度场梯度）"的先验约束下可解，仅余三个面内刚体模式（共模平移×2+整体旋转）由表面边界固定；配套反演方法为：先由各端口自感一维反解法向位移场初值（验证误差 5.3µm），再以工作点数值雅可比执行高斯-牛顿迭代（验证：法向 5.4µm、面内 8.1µm）。该变体以约 8 倍位姿分辨率代价换取模拟前端通道数减半。

### 3.3 有益效果

1. **六维力可测**：单元级 5 自由度 + 阵列级 Mz 重建，全部经真实电磁有限元验证（非等效电路近似）；
2. **交错锚点高度以纯机械结构（基座凹槽）消除共模简并**，无需增加线圈、通道或异形线圈，不占行程、不增加活动件；相对同高度锚点方案，共模可观测度提升约 74 倍，联合反演条件数从 >2000 降至 55；
3. **开路协议**从测量体制上消除第三线圈串扰（151%→0.02%）；
4. 联动变形（弹性表面一点受力多单元响应）在本架构下不是干扰而是被完整重建的状态量；
5. 束绕圆环线圈结构使全部匝共位，互感严格按匝数平方缩放，标定模型简单；线圈无叠绕高度，整体极薄；
6. 分辨率高：千分之一互感测量精度下法向亚微米、倾角角分级；
7. 半端口变体为成本敏感场景提供通道减半选项。

## 五、具体实施方式（实施例参数）

- 线圈：15 股 Ø0.05mm 漆包线捆束（束径≈0.22mm），绕成中径 Ø5mm 单环；单环自感≈10.3nH，束绕（×15²=225）≈2.3µH，直流电阻≈2.0Ω；
- 阵列：蜂窝中心距 5.2mm（相邻环净间隙 0.2mm）；
- 行程：表层-锚点环心距静息 2.5mm、全压缩 1.0mm、标称工作点 1.75mm；
- 交错锚点：三角格三色化取一色下沉 0.9mm（可选 0.8–1.0mm）；
- 弹簧：铜漆包线绕制，两端开路；
- 典型耦合量（标称点、束绕值）：表层-自身锚点 0.44µH（k≈0.19）、相邻表层-表层 0.17µH、相邻表层-锚点 0.02µH；
- 检测：5–15MHz 正弦驱动（低于自谐振），驱动电流 ~10mA，相干 IQ 检测取正交分量得 ωM；正交分量对应互感（几何量），同相分量对应耦合电阻（用于温度补偿）；多频点（3–5 点）拟合分离 jωM 与寄生项；
- 非活动线圈开路（≥100kΩ）；
- 反演：观测相对变化归一 + 各自由度全量程归一的加权最小二乘；方案 A 用标称点雅可比截断伪逆迭代；串联变体用"自感自举初值 + 工作点中心差分雅可比高斯-牛顿"；
- 全部验证数据存档：`reports/honeycomb_*.json`、`honeycomb_spectrum19.npz`（Git 提交 3dc7cf2 与 818266f）。

## 六、权利要求布局建议（供代理人参考）

1. **独立权利要求（装置）**：一种电磁式力传感阵列，包含多个传感单元（表层线圈+固定锚点线圈+弹性支承）呈蜂窝排列，**其特征在于：锚点线圈按预定着色规则设置至少两种固定高度，使任一单元的自身及相邻锚点线圈集合中包含至少两种高度**。
2. 从属：锚点高度差为线圈标称间距的 0.3–0.6 倍（实施例 0.9mm/1.75mm）；下沉锚点嵌入刚性基座凹槽。
3. 从属：线圈为多股细线捆束绕制的单环（束径 < 环径 1/10）。
4. 从属：弹性支承为两端开路的导线弹簧。
5. **独立权利要求（方法）**：驱动任一线圈、以相干幅相检测测量其与自身锚点及相邻单元双层线圈的互感，**非活动线圈保持开路/高阻**；由互感观测联合估计各单元表层线圈位姿场，再经弹性映射重建表面六维力/力矩分布，其中绕法向扭矩由多单元切向位移场旋度重建。
6. 从属：按着色分组的频分复用同时驱动。
7. 从属：IQ 正交分量提取互感、同相分量用于温度/损耗补偿；多频点拟合分离寄生项。
8. 从属（串联变体）：上下线圈按互感增强方向串联为单端口；以端口自感一维反解法向位移初值、继以工作点雅可比迭代反演。
9. 从属：柔性连续表面先验（倾斜=高度场梯度）约束下的降维反演。

## 七、与最接近现有技术的区别点归纳（新颖性要点）

| 区别特征 | 现有技术 | 本发明 |
|---|---|---|
| 参考线圈高度 | 同一平面 | **≥2 种交错高度（三色格下沉）** |
| 共模剪切/弯矩 | 简并不可测 | 可观测度提升 74 倍，满秩 |
| 非活动线圈处理 | 未规定/谐振端接 | **强制开路协议**（有定量依据） |
| 联动变形 | 视为串扰 | 作为状态量联合重建 |
| Mz | 单元级不可测（旋转对称） | 阵列级旋度重建 |
| 线圈形态 | 螺线管/平面螺旋 | 捆束单环（共位近似、无高度） |

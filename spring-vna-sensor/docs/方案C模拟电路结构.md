# 方案C（无源反射环）模拟电路结构推荐

适用：底层 19 有源线圈（15 股捆束 2.3µH/2Ω，交错锚点）+ 顶层无源单匝短路铜环（7.4nH，Q=28）。
观测量 = 底层端口有效电感 Im(Z_eff)/ω：**19 个自阻抗 + 42 个邻边互阻抗**。
工作点：f0 = 2.5MHz，fs = 10MSps（fs/4 架构），驱动 10mA。

---

## 0. 方案C 对电路的两个特殊要求（与 A/B 的本质区别）

1. **自阻抗测量**：主观测是"驱动线圈自己的端口阻抗变化"——必须在驱动同一线圈的同时精确测它的 V 和 I。这是 LCR 表问题，不是纯互耦收发问题。
2. **精度指标押在载波上**：自观测反射 −44~−121nH 骑在 2317nH 固定自感上；要分辨反射的 1e-3（44pH）= **载波的 19ppm**。直接数字化需要 ~94dB 瞬时动态范围——不现实，**调零是结构性必选**，不是优化项。

好消息：方案C 的载波（底层自感 L_bb、底-底互感 M_BB）全部由**刚性基座上的固定几何**决定——载波本身不随被测量变化，调零值 = 静态标定表 + 慢漂跟踪，比方案A 的"预测式调零"更简单可靠。

---

## 1. 推荐拓扑：四线 Kelvin 双总线 + 电流参考式矢量调零

```
                          ┌─────────── 力总线 F (载驱动电流) ───────────┐
  DDS ── LPF ── PA ── Rs ─┤                                            │
         (2.5MHz)     │                                                │
                  [差分I-sense放大] ──→ ADC2 (电流通道, 幅相基准)         │
                      │                                                │
                      │      每线圈热端:                                │
                      │        力开关 SPST ──┐                          │
                      │        感开关 SPST ──┼── 线圈 ── 公共地          │
                      │        (均低C_off)   │  (冷端固定接地)           │
                      │                     │                          │
  数字复增益 α=(A,B) ──→ 2×MDAC(sin/cos) ──→ V_null                     │
                          ┌────────── 感总线 S (高阻, 零电流) ──┤        │
    高阻缓冲(≥100kΩ‖≤3pF) ←┘              │                            │
       └→ 求和节点 (V_S − V_null) → PGA(20/40dB) → BPF(2.5MHz) → ADC1   │
                                                     ↓
                                       fs/4 数字IQ → Im(信号)/Re(温度计)
```

### 每线圈开关配置（与基础方案的关键差异）

| | 基础方案 (A) | **方案C** |
|---|---|---|
| 每线圈开关 | 1× SP3T（驱/收/开路） | **2× SPST：力开关（→F总线）+ 感开关（→S总线）** |

理由：**驱动电流 10mA 流过力开关的 Ron（~2Ω）产生 20mV 压降，Ron 温漂 ~10mΩ/K → 100µV/K 误差**，是 7µV 分辨目标的 14 倍/K——自阻抗测量绝不能在开关的电源侧取电压。感开关是零电流的 Kelvin 抽头（Ron 完全不入误差），直接从线圈热端取真实端口电压。

三种驻留态：
- **自观测**：线圈 k 力开关+感开关同时闭合 → ADC1 测本端口电压（已调零），ADC2 测电流 → Z = V/I
- **边观测**：线圈 i 力开关闭合（驱动），线圈 j **感开关**闭合（接收）——接收是电压测量，走同一条感总线、同一条接收链
- **开路**：双开关断开。感开关 C_off 串到 S 总线：线圈-线圈经两个 C_off 串联（~0.125pF ≈ 510kΩ@2.5MHz）> 230kΩ 协议要求 ✓

**电路复用是这个拓扑的核心收益**：自观测和边观测共用同一条"感总线→缓冲→调零→PGA→ADC1"链，无需第二套接收电路；区别只在开关图案和调零表取值。

## 2. 调零注入：电流参考式矢量调零（与方案A 的不同点）

方案A 的调零抵消"预测的互感信号"；方案C 抵消的是**大而恒定的载波**：

| 驻留类型 | 载波成分 | 调零值来源 |
|---|---|---|
| 自观测 | Z_nom·I ≈ jω·2317nH·10mA ≈ **361mV**（+20mV 阻性） | 静态标定表（每线圈一个复数）|
| 边观测 | jω·M_BB·I ≈ **10.8mV** | 静态标定表（每边一个复数）|

**实现：V_null = α·(源相干正交对)**，α = (A,B) 复增益由两片乘法 DAC（MDAC，如 AD5453 类，µs 建立）实现，正交对从驱动 DDS 同一相位累加器取 sin/cos——**与驱动共时钟共参考**，源幅度漂移在 (V−V_null)/I 比值中一阶抵消。

规格链核算（自观测，最严）：
- 调零深度要求：361mV 压到 <1mV 残差（PGA 40dB 后 100mV，ADC 不饱和）→ 抵消精度 0.3% → **12bit MDAC 富余**
- 残差测量把差值精确数字化，调零本身无需 19ppm 精度——但调零源在一帧内的**稳定度**需 <7µV/361mV = 2e-5：共时钟数字合成 + 每帧参考驻留校准链路增益，达标
- 更新速率：每驻留换表值 → MDAC 建立 <1µs（在 3µs 开关建立窗口内完成）

## 4. 温度与漂移管理（方案C 的免费红利）

1. **反射 Im 分量固有免疫**：1.9e-4/K（短路环 1/Q² 压制）——±5K 内不做任何补偿
2. **Re 分量 = 免费的分布式温度计**：反射实部 ∝ 环电阻 R(T)，每环独立读出温度，用于 >±5K 时的模型修正与健康监测（环断裂/脱落即刻可见）
3. **载波慢漂**：基座铜膨胀 ~17ppm/K 使 L_bb 漂 ~40pH/K——量级与分辨率相当，由**调零表慢速跟踪环路**（~Hz 带宽）吸收：慢漂进调零、帧率信号通过，天然高通分离
4. **链路增益/相位**：每帧 1 次参考驻留（驱动经衰减器直入感链）+ 1 次电流基准驻留，全链漂移比值消除

## 5. 与 1DAC+1ADC 基础方案的差异清单

| # | 差异 | 增量成本 |
|---|---|---|
| 1 | 每线圈 1× SP3T → **2× SPST**（力/感 Kelvin 分离） | +19 只开关 |
| 2 | 新增**感总线**（高阻电压总线，与力总线平行走线） | 布线 +1 网络 |
| 3 | 新增**矢量调零源**：2× MDAC + 求和节点 | ~$3–5 |
| 4 | **推荐 ADC 第二通道**（同步 V/I）——严格说仍可 1ADC 分时，但 C 的自阻抗测量从实时比值获益最大 | +$3–8 |
| 5 | PGA 3 档 → 2 档（调零后动态范围收窄） | 简化 |
| 6 | 调零表：19 自 + 42 边 静态复数标定表 + 慢跟踪环路（固件） | 固件 |
| 7 | 数字侧：全耦合正演模型（19×19 复矩阵）+ 双速反演（54 强方向快 + 3 弱共模慢） | 固件（~100–200 kFLOP/元/帧） |
| 8 | 顶层：**零电路**——无引线、无开关、无电容 | −19 通道的运动层互连 |

总 BOM 增量约 $10–15（对比基础方案），换来：自阻抗 19ppm 级测量能力、运动层零电路、温度免疫。

## 6. 备选拓扑说明（为什么没选）

- **自平衡电桥（LCR 表经典：冷端虚地 TIA 取电流）**：精度谱系最正，但 2.5MHz 下 TIA 驱动感性源的环路稳定性需精心补偿，且冷端不能共地（与 19 线圈公共接地的阵列布线冲突）。Rs+Kelvin 达到同级精度且结构简单，故选后者
- **谐振读出（底层线圈加谐振电容测频移）**：把 19ppm 电感变化转为频率测量确有吸引力，但与"非活动线圈必须开路"协议冲突（谐振负载是判决过的灾难项），且引入 C 的温漂——否决
- **每线圈独立接收链（全并行）**：帧率 >10kHz 时再升级，拓扑不变，感总线分段即可

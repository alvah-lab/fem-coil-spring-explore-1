# 霍尔磁体触觉 vs 方案C 涡流反射环：第一性原理对比（5mm 与 1mm pitch）

对象：帕西尼一类"磁体埋在弹性体、下方三轴霍尔读场"的通用结构（按公开资料的通用做法，不涉及其内部实现）与方案C（无源铜环 + PCB 有源螺旋 + 交错高度）。

## 0. 目标效果

每单元三轴力，阵列级六维，位移分辨率 1µm 量级，帧率 ≥100Hz，触摸 ±20K 温差物体读数漂移 <1%，机器人手上的磁场/金属环境可用。

## 1. 5mm pitch 对比

两者都是"近场随距离幂律衰减"的位移换能器：霍尔读偶极场 B ∝ m/r³，涡流读 M²/L ∝ 1/r⁶。

| | 霍尔 + 磁体 | 涡流反射环 |
|---|---|---|
| 灵敏度 d lnS/dz，间隙 2.5mm | ≈1/mm | ≈1.4/mm |
| 换能器位移分辨率 | Ø3×1 N35 在 2.5mm: 37mT, 30µT/µm; 1µT 噪声 → **0.03µm** | 原型 0.7µm; ASIC 热噪声地板 0.01~0.05µm |
| 换能器温漂 | NdFeB 剩磁 −0.11%/K + 霍尔灵敏度 ±0.05%/K → **1.4~2µm/K**，磁体温度不可测 | 短路环虚部 1/Q² 免疫 → **0.13µm/K**，实部通道可测环温并修正 |
| 单元级自由度 | 一颗三轴霍尔 3 个数 → 只解平移，倾斜简并 | 自观测+6 邻边+两种高度 → 5 自由度，cond 2.7 |
| 邻元场串扰 | (3/5)³ ≈ 20%，联合反演 | 杂化路径，全矩阵模型 |
| 邻元力学串扰 | 磁体互吸斥，Ø3×1 在 5mm ≈ **43mN**，∝1/r⁴ | 环间涡流力 nN 级 |
| 动层 | 无源磁体 | 无源铜环 |
| 固定侧每单元 | **一颗硅片**（霍尔 IC 或自研 die） | PCB 铜螺旋，19~37 单元共享一颗 ASIC |
| 密度上限 | 封装霍尔 → pitch ≥4mm | 尺度不变，可到 1mm（Q ∝ L² 退化） |
| 外部干扰 | 地磁 50µT ≈ 2µm 假位移随姿态变；电机/钢件/磁体 mT 级 | DC 磁场免疫；**导电物体接触**加反射，皮肤 1mm 时约 13% |
| 附加通道 | PCB 侧芯片温度 | 环温（实部）、10kHz 振动 |
| 标定 | 磁化 ±3~5%、位置公差，逐单元 | 几何由光刻/冲压定 ±1% |

**结论（5mm）**：差别不在分辨率。决定性的四件事：① 摸热物体时磁体剩磁变化等价 50~80µm 假位移且不可测，涡流 5µm 且可修正；② 磁体间力形成非线性力学耦合；③ 霍尔每单元一颗硅片，涡流硅共享；④ 霍尔怕磁环境，涡流怕导电物体（需补定量分析与屏蔽设计）。霍尔的优势：单元独立、直流、无射频、现成 IC 起步快、单颗分辨率比原型强 20 倍。

## 2. 1mm pitch 对比（s = 0.2 缩放）

| 量 | 霍尔 | 涡流环 |
|---|---|---|
| 信号相对量 | 不变 | 不变 |
| 位移分辨率 | ∝s → 0.006µm | ∝s → 原型 0.14µm / ASIC 0.01µm |
| 换能器温漂 | 0.3µm/K，相对间隙不变 | 0.026µm/K |
| 磁体间力/间隙 | **不变 ~5%** | 无 |
| 均匀外场 | 相对不变 | 免疫 |
| 导电物体（皮肤 1mm 不缩） | — | (0.5/1.5)⁶ ≈ **1.4e-3**，比 5mm 小 100 倍 |
| 品质因数 | 不适用 | 环 Q ∝ s²√f：8MHz 3.5 → 31.25MHz ≈7 → 100MHz ≈12 |

涡流环在 1mm 的代价：频率 30~100MHz（环 Q≈10 仍可用：虚部减 1%，温漂 0.05µm/K，实部温度通道更强；线圈 SRF ~400MHz 不受限；f0=125/4=31.25MHz 每周期恰 4 点）；PCB 3.5mil 下每层 2.5 匝，需 2/2mil 或 4~6 层柔板；泡棉 0.5mm 或改凝胶。收益：**400 个环是一张蚀刻铜箔**，无极性无装配；导电物体干扰基本消失。

霍尔在 1mm 的代价：**硅片面积 = 皮肤面积**（自研霍尔成像阵列，指尖 400mm² 硅，大 die 或拼片），涡流硅面积约皮肤 1/20；400 颗 Ø0.6×0.2 微磁体带极性贴装（磁化弹性体可免贴装但信号弱 1~2 量级）。磁体耦合与温漂比例原样带到小尺度。

**结论（1mm）**：天平明显倒向涡流环。其新代价是电路与 PCB 工艺，可用频率和层数换；霍尔的代价是硅面积与微磁体装配，是结构性的。

## 3. 涡流方案待补的两项

1. 导电物体接触干扰的定量分析（环孔尺寸、皮肤厚度、随动导电膜屏蔽方案）。
2. 31.25MHz 下 Ø1mm 环 + 10 匝线圈的实际反射与 Q（FastHenry，约一天）。

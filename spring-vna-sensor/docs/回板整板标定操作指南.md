# 回板整板标定操作指南（含数字孪生实跑预期）

本指南按 8 块一体标定板的流程写，每一步都给出"孪生实跑得到的数字"作为预期；回板后同样的步骤在真板上做，只把数据源从 `twin` 换成 `board`。孪生实跑记录（GUI 离屏自动走完全流程，`hardware` 噪声预设，每次 100 帧）存放在 `reports/bringup/plates/`：`run_summary.json`、`plates_calib_twin.csv/json`、各步截图 `*.png`。

## 0. 准备

硬件（回板后）
- K18 板背面：在 **HLOC2 (60.02, 27.08)** 和 **HLOC5 (59.47, 52.57)** 两个 Ø2.2 孔从背面拧入 M2 螺钉（露出正面 ≥ 4 mm），其余四孔不用。
- 8 块板（A0, A1C, A2C, B1, B2, B3, D, E1）+ 铜环 Ø5.0/Ø3.0×0.2 若干（B/E 板各 19 个，A1C 7、A2C 6、D 8）。环套在凸柱的锥尖上滑到底、贴平。
- 板的取向 k：围框 +x 侧的三角标指向板上 L19（单元 18）方向为 k=0，逆时针每转 60° k+1。板上 12 个孔任一取向都能套住两颗螺钉。
- 打印件核对：围框厚度设计 2.0 mm（千分尺），偏差按比例记到 `plates_K18.json` 的 `H_seat_mm`。

软件
```bash
cd spring-vna-sensor/host && source ../../venv/bin/activate
SCENE=rest NOISE=hardware ./run_gui.sh twin     # 演练
./run_gui.sh board                              # 真板 (192.168.2.128:5000)
```
左侧标签"回板测试"，六页：状态 / 单驻留 / 基线 / 单元扫描 / 垫片标定 / 整板 / 噪声-稳定性。

## 1. 状态页

点"刷新寄存器"。孪生实跑：

```
DEVICE_ID 0xe7f10001   FW_ID 0x54330001
STATUS 15  running=1 adc_locked=1 phy=1 link_ready=1 fault=0
N_DWELL 63   DWELL_NSAMP 12496
```
真板：同上，另看 LINK_STATUS timeouts=0 faults=0、ERR_CNT tx_drop=0。真板此时 RF_EN 保持 0，按 `firmware/docs/BRINGUP_0917.md` §1–§2 做轨检查后再勾。

## 2. 无环基线（板上什么都不放）

1. 孪生：垫片标定页 →"全部无环"（真板：裸板）。主界面诊断栏出现"无环签名：跟踪器暂停"，六角图全零。
2. 基线页：帧数 100 →"采集基线（无环）"，约 1.5 s。
3. "应用为载波"→"保存 JSON…"（`baseline_K18_<日期>.json`）。

孪生实跑（hardware 噪声）：

| 量 | 数值 |
|---|---|
| 自观测 ΔL(实测−模型) 中位 | +0.001 nH |
| 边 ΔL 中位 | +0.001 nH |
| 自观测 σ_L 中位 | 0.023 nH（≈2 µm） |
| 边 σ_L 中位 | 0.0004 nH |

真板预期：自观测 ΔL 在 ±1–3 nH（线圈 L 与层高的制造偏差，这就是模型-实物偏差表）；边 ±0.1 nH；σ_L 自观测 < 0.03 nH 说明噪声底达标。**之后所有板的"实测 ΔL"都是相对这条基线。**

## 3. 整板页 —— 逐板逐取向

每条记录的操作固定四步：
1. 选板号、取向 k。面板显示"取向 k → 板上在位单元 […]"和每格 gap/倾角/偏移，**和手里的板核对一遍**。
2. 装板：孪生点"孪生: 装上此板"；真板套上螺钉、方向标对准 k。等 1–2 s。
3. "记录整板"（100 帧，约 1.5 s）。表格 61 行：实测 ΔL / 模型 ΔL / 差 / σ；信息栏一行汇总。
4. 换取向或换板，重复。最后"保存 CSV+JSON…"。

建议顺序与孪生实跑结果（100 帧，hardware 噪声）：

| 板 / k | 在位单元 | 自反射 实测/模型 中位比 | 自反射差 rms / max (nH) | 边差 rms / max (nH) | 无环单元残差 max (nH) |
|---|---|---|---|---|---|
| A0 k0 | 无 | — | — | — | 0.007 |
| A1C k0 | 1,3,6,9,12,15,17 | 1.0000 | 0.002 / 0.004 | 0.00007 / 0.0002 | 0.008 |
| A1C k1..3 | 同上（平放/倾斜互换） | 0.9999–1.0000 | 0.003–0.004 / ≤0.008 | ≤0.0001 / ≤0.0002 | ≤0.007 |
| A2C k0,2,4 | 0,5,8,11,14,16 | 1.0000 | 0.003–0.005 / ≤0.010 | ≤0.0001 / ≤0.0003 | ≤0.009 |
| A2C k1,3,5 | 2,4,7,10,13,18 | 1.0000 | 0.003 / ≤0.004 | ≤0.0001 / ≤0.0003 | ≤0.008 |
| D k0..5 | 每次 8 个（4 对） | 1.0000 | 0.002–0.004 / ≤0.008 | ≤0.0001 / ≤0.0002 | ≤0.008 |
| B2 k0 | 全 19 @1.75 | 1.0000 | 0.004 / 0.008 | 0.0001 / 0.0003 | — |
| B1 k0 | 全 19 @1.35 | 1.0000 | 0.004 / 0.009 | 0.0003 / 0.0004 | — |
| B3 k0 | 全 19 @2.53 | 0.9999 | 0.004 / 0.008 | 0.00006 / 0.0002 | — |
| E1 k0 | 全 19 轮廓 | 1.0000 | 0.004 / 0.009 | 0.0001 / 0.0003 | — |

各板自反射模型值（供核对量级，nH，相对无环载波）：下沉单元（类 0，含中心 9）@1.75 ≈ −19.8，@1.35 ≈ −40，@2.53 ≈ −7.6；标称单元 @1.75 ≈ −53，@2.53 ≈ −18.2。倾斜 5° 使自反射略减（<1 %），邻边出现 ±方向不对称；偏移 0.5 mm 自反射几乎不变，沿偏移方向的两条边一增一减。

真板判读（把每块板的汇总抄进表格再看）：
- **中位比**偏离 1：全体同向 → 间隙零点/层高系统差（比 0.95 ≈ 间隙比设计大 0.05 mm，先怀疑打印件高度和阻焊厚度）；个别单元离群 → 该线圈的 L 偏差（应与 §2 基线里该单元的 ΔL 一致）。
- **自反射差**：真板目标 < 0.5 nH（对应 < 50 µm）；A1C 与 B2 同一单元的差 = 网络相互作用项的模型误差。
- **边差**：真板目标 < 0.02 nH；D 板阶差对（1.35/2.53）的边最敏感。
- **无环单元残差**：> 0.05 nH 说明邻环耦合进自观测的项与模型不符（或环放错格了——先看单元扫描页）。
- 任一板的表格里某一行 σ 明显大于其它行 → 该驻留链路有问题（PGA 饱和、开关），去单驻留页单测那条。

## 4. 主界面跟踪器在各板上的表现（次要，仅供观察）

标定用的是整板页的 61 观测，不依赖跟踪器；主界面只用来看"像不像"。孪生实跑（每板装上后连续跑 240 帧 ≈ 3 s）：

| 板 | 真值中心 w | 跟踪器中心 w（帧 30 / 60 / 240） | 复位次数 | 说明 |
|---|---|---|---|---|
| B2 | −780 µm | −787 / −781 / −783 | 2 | 30 帧内收敛，全阵列误差 ≤ 5 µm |
| B3 | 0 | −12 / −10 / −3 | 1 | 静息工作点 |
| B1 | −1180 µm | −1162 / 0(复位) / −1179 | 8 | 1.2 mm 突变要 ~3 s、多次复位后才稳，最终 ≤ 14 µm |
| E1 | −1180 µm | −1125 / −1188 / −1230 | 1 | 中心误差 ~50 µm、一圈 ~40 µm、最大 75 µm：刚性阶梯轮廓与跟踪器的柔性面先验不符，属预期 |
| A/D 板 | — | 缺席单元灰显、位姿冻结 | — | 自动"部分放环"，在位单元 w 收敛到板设计值 |

注意：换板时跟踪器会复位几次是正常的；只有整板页的记录才是标定数据。w 是相对静息间隙 2.53 mm 的偏移。

## 5. 噪声/稳定性页（E1 装上后）

孪生实跑：帧率 75 Hz、丢帧 0、饱和 0、链路超时 0、FAULT 0；σ_L 自观测中位 0.023 nH（≈2 µm），边 0.0004 nH；σ|V| 中位 10 µV。真板要求：帧率 77 Hz、丢帧 0、σ_L 自观测 < 0.03 nH、边 < 0.001 nH。

## 6. 时间预算（真板）

基线 2 min；每块板每个取向约 1 min（装板、核对、记录）；建议第一天做 A0、A1C×4、A2C×6、D×6、B2、B1、B3、E1 共 21 条记录，约 40 min 纯操作。全部存一个 CSV/JSON，之后用 `PlateLog` 的 JSON 做拟合（间隙零点、每单元 L 比例、相互作用项）。

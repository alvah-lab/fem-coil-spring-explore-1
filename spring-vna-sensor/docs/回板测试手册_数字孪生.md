# 回板测试手册（数字孪生演练版）v0

目的：K18 回板（2026-09-17）前，把回板后要做的每一步测试在数字孪生上走一遍，熟悉 GUI 的"回板测试"面板，并给每一步留下"预期数字"。回板后只换数据源（`twin` → `udp`），操作不变。

配套：GUI 左侧"回板测试"标签（`honeycomb_host/gui/bringup.py`），核心逻辑 `honeycomb_host/bringup.py`，孪生场景 `Scenes.no_rings()` / `Scenes.shim(...)`，固件 `prototype-track3-1:firmware/`（协议 v0.1）。测试阶段划分依据见前文讨论：无环 → 单环 → 多环。

## 0. 启动

```bash
cd spring-vna-sensor/host && source ../../venv/bin/activate
# A. 进程内孪生（最方便，面板里可直接切场景）
./run_gui.sh twin              # 或 python3 -m honeycomb_host.gui.main --source twin --scene rest --noise hardware
# B. 走 UDP 的模拟设备（和真板同一条路径：命令口 5000 / 数据口 5001）
python3 -m honeycomb_host.sim_device --shim 9:1.75:0:0 --noise hardware &   # 单元 9 放一个环, 间隙 1.75, 其余无环
./run_gui.sh udp --device 127.0.0.1:5000
# C. 真板（回板后）
./run_gui.sh udp               # 默认 192.168.2.128:5000, 连接时自动 identify → HOST_PORT → RUN
```

噪声预设：演练用 `hardware`（含 ADC/前端噪声），核对数字用 `off`。

## 1. 状态页 —— 链路与寄存器

| 操作 | 孪生预期 | 真板预期 |
|---|---|---|
| 刷新寄存器 | DEVICE_ID 0xe7f10001，FW_ID 0x54330001，STATUS running=1 adc_locked=1 phy=1 link_ready=1 | 同左；LINK_STATUS timeouts=0 faults=0；ERR_CNT tx_drop=0 |
| 勾 RF_EN | 无影响（孪生不建 PA 模型） | A704 PA_RUN=1，此后 I 通道出现驱动电流（\|I\| ≈ 100 V/A × 10 mA = 1 V） |
| STOP / START | 帧停/续 | 帧停/续；STOP 后 A704 全断、PA 关 |

真板上 RF_EN 之前必须完成 `firmware/docs/BRINGUP_0917.md` §1–§2 的轨检查。

## 2. 单驻留页 —— 逐级调信号链

把整帧换成只测一条驻留（固件 N_DWELL=1），显示该驻留的 \|V\|、∠V、\|I\|、Z、L、R 及随时间曲线。

演练脚本：
1. drv=9 sns=9 PGA ×1 → "只测这一条"。孪生（rest，全部有环）预期 L ≈ 载波 L₉ − 18.2 nH（下沉单元静息反射 ≈ 7.6 nH，标称 ≈ 18.2 nH；单元 9 是下沉单元，预期 ≈ −7.6 nH），R ≈ 1.8 + 3 (Ron) Ω。
2. drv=9 sns=9，孪生场景切"全部无环"（垫片标定页的按钮）：ΔL(模型) 应回到 0 ± 噪声。
3. drv=9 sns=10 PGA ×100（边观测）：\|V\| 数十 mV 量级，ΔL 量级 0.2–0.6 nH。
4. ref 勾选，drv=sns=31，PGA ×10：\|V\| ≈ 200 mV（20 mV × 10）。
5. vna 勾选（电流标定）：V≈0，\|I\| ≈ 1 V。
6. "恢复默认 63 表" 回到整帧。

真板差异：步骤 1 无环时 R 的实测值就是 R_coil + Ron，记下来；步骤 4/5 给链路增益和 Rs×AD8138 的实际比例。

## 3. 基线页 —— 无环载波标定（回板第一天最重要的一步）

1. 场景 "全部无环"（真板：板上确实没有环）。
2. 帧数 100 → "采集基线"。得到 61 观测的 L/R 与 σ_L，表格里 "ΔL nH" 列是实测减模型载波。
3. 孪生预期：ΔL 全部 ≈ 0（噪声 `off` 时 |ΔL| < 2e-3 nH）；自观测 R ≈ 4.8 Ω（1.8 + 3）。
4. "保存 JSON…"（建议命名 `baseline_K18_<日期>.json`），"应用为载波"：此后跟踪器的反射 = L − 实测基线，观测面板的"反射"图应归零。
5. 真板预期：ΔL 自观测在 ±1–3 nH（线圈 L 的制造偏差 + 叠层实际厚度），边 ±0.1 nH；这就是模型和实物的偏差表，本身是成果。σ_L 自观测中位 <0.01 nH 说明噪声底达标。

## 3b. 部分放环时主界面的行为（自动）

- 跟踪器按每个单元的自观测反射（|ΔL| ≥ 3 nH）自动判定"环在位"，连续 3 帧一致才切换。缺席的环从模型网络里移除、位姿冻结为 0，六角图上显示为灰色；诊断栏显示"部分放环: 在位 k/19"。全部缺席 = "无环签名"，跟踪器暂停。
- 跟踪器的 w 是**相对静息间隙 2.53 mm** 的偏移：垫片 1.75 mm → w ≈ −0.78 mm，1.35 mm → −1.18 mm，2.53 mm → 0。部分放环时跟踪器自动用刚性映射（无柔性先验）；换板后位姿从 0 重新收敛，十几到三十帧、最多一次复位。5° 倾斜格因没有倾斜自由度会在 u/v 上出现伪影。
- 单环下面内 u/v 和倾斜不可观测（只有一个环、六条边），主界面只看 w；倾斜/偏移的验证看垫片标定页的邻边不对称。

## 4. 单元扫描页 —— "环放在哪、放对了没有"

19 根柱 = 每单元自观测 ΔL（相对基线，EMA 平滑），下方给选中单元的 6 条邻边 ΔL。

1. 基线已应用后，场景切 "放置垫片+环（其余无环）"（单元 9，间隙 1.75）。
2. 预期：只有第 9 根柱 ≈ −19.6 nH，其它 ≈ 0；单元 9 的邻边（4,5,8,10,13,14）各 −0.3 ~ −0.6 nH，其它单元的边为 0。
3. 把间隙改 1.35 再放：柱变为 ≈ −40 nH；改 2.53：≈ −7.6 nH。
4. 真板：放一个环后柱的位置要和物理位置一致（主机单元号 = 板上 COILnn = SWnn，已核对为恒等映射）。

## 5. 整板页 —— 8 块标定板，一板一记录（主用）

标定件已改为 8 块一体 SLA 板（`reports/calib_plates/`，布局表 `honeycomb_host/data/plates_K18.json`）。板背面 HLOC2/HLOC5 两颗 M2 螺钉定位，每块板配同孔位压板压住铜环（螺母拧紧），板可绕阵列中心转 60k°（k = 0..5，方向标指向板上 +x / 单元 18 方向为 k = 0）。

| 板 | 环 | 内容 | 建议取向 |
|---|---|---|---|
| A0 | 0 | 空白，塑料件对基线的影响 | k=0 |
| A1C | 7 | 类 0：中心 + 3 格平放 1.75，3 格 5° 倾斜 | k=0,1（平/倾斜互换）再 2,3 |
| A2C | 6 | 类 1：3 格平放，3 格偏移 0.5 mm | k=0..5（k 奇数落到类 2） |
| B1/B2/B3 | 19 | 全阵列 1.35 / 1.75 / 2.53 | k=0 |
| D | 8 | 2 对等高 1.75 + 2 对阶差 1.35/2.53 | k=0..5（覆盖 24 条边） |
| E1 | 19 | 按压轮廓 1.35/1.75/2.53 | k=0 |

操作（孪生与真板相同）：
1. 板号、取向 k 选好，面板显示该取向下板上哪些单元有环及各自 gap/倾角/偏移——**和手里的板核对**。
2. 孪生：点"孪生: 装上此板"；真板：把板套上螺钉，方向标对准 k。
3. "模型预测"先看整板 61 观测的预测 ΔL；"记录整板"采 N 帧（默认 100），表格逐观测给出 实测 ΔL（相对无环基线）/ 模型 ΔL / 差 / σ，信息栏给汇总：自反射实测/模型中位比、差 rms/max、边差 rms/max、无环单元残差。
4. 换取向或换板重复；"保存 CSV+JSON…"一次写出全部记录（CSV 每板每取向 61 行）。

判据与解读：
- 孪生（噪声 off）：自反射差 < 0.001 nH，边差 < 0.0002 nH——这是链路本身的极限。
- 真板：自反射中位比偏离 1 的部分 = 间隙零点/层高的系统误差（比如全体 0.95 → 间隙比设计大约 0.05 mm）；单个单元离群 = 该线圈 L 的制造偏差；A1C 与 B2 同一单元的差 = 网络相互作用项的模型误差；无环单元的残差 > 0.05 nH 说明邻环耦合项有误。
- 全阵列板（B1/B2/B3/E1）装上后主界面跟踪器会跑（19 环都在），E1 应显示中心下压的轮廓；A/D 板只有部分环，跟踪器自动进入"部分放环"（缺席单元灰显）。

旧的"垫片标定页"（单片六边形垫片）保留在面板里，用法不变，仅供单点补测。

## 6. 噪声/稳定性页

窗口 200 帧的每观测 σ_L（对数柱状图）、帧率、丢帧、饱和/链路超时/FAULT 计数，并把自观测 σ_L 折算成 µm（≈11 nH/mm）。

预期：孪生 `hardware` 噪声下自观测 σ_L 中位 ~0.01 nH（≈1 µm），边 ~1e-4 nH；真板要求 σ_L 自观测 < 0.02 nH、边 < 5e-4 nH（5 pH 绝对底），帧率 77 Hz，丢帧 0，超时/FAULT 0。切场景或换驻留表后要"重置统计"，否则窗口里混着两种状态。

## 7. 回板后的顺序（与 BRINGUP_0917 衔接）

1. §1 状态页 → 轨检查通过后勾 RF_EN。
2. §2 单驻留：先 ref/vna 两条（不依赖线圈），再自观测 ×1，再一条边 ×100，看饱和标志。
3. §3 无环基线 100 帧 → 保存 → 应用。
4. A0 板 → 与裸板基线比（塑料件应无影响）；A1C k=0 → §4 单元扫描确认 7 个环位置对 → §5 记录；然后 A1C 其余取向、A2C、D、B2、B1、B3、E1。
5. 每块板每个取向一条记录，全部存一份 CSV/JSON；B 组三块给每单元 3 点间隙曲线。
6. 全部放环 + 泡棉 → 回到主界面跟踪器（此时基线已是实测值）。

## 7b. 会话日志

工具栏“日志”按钮或 `--log`：记录操作事件 + 每帧跟踪器/掩码/观测原始数据 + 原始帧到 `host/logs/session_*/`，`scripts/analyze_session.py <目录> --plot x.png` 离线分析。主界面出现无法解释的跳变时先开它。

## 8. 已知限制

- 固件 v0.1 只回 I/Q 累加值，没有原始样本；PGA 毛刺、饱和波形要用示波器看 X3/X2。如需要，固件可加回 4096 样本 BULK_READ（改动小，需重出位流）。
- 旧垫片标定页的"模型预测"只对"其余无环"成立；整板页的预测按整板布局计算，无此限制。
- 孪生不模拟 PA 开关、开关 Coff 泄漏的温漂；真板这些量会进入基线的 R 列和 σ。

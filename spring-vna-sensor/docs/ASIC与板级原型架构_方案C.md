# 方案C ASIC 接收架构与板级原型路线（2026-09-08 定稿，图表35/36）

## 1. ASIC 核心转变：每线圈一端口，全 Z 矩阵
每端口同时测 V（电流源驱动故 I 已知）→ Z 矩阵精确解，**不再需要开路协议、C_off 阈值、共享总线、Kelvin 电流通道**；互易性 Z_ij=Z_ji 免费标通道；每观测积分整帧（SNR +8×）。驱动可按三色格分 3 相位轮流以省功耗。

## 2. 接收通道
- 电流源驱动（Mk×k + Mc 共栅），线圈电压 <0.5V（如 5mA），高阻缓冲 ×1~2；放大靠累加不靠 LNA。
- 底板四相采样进 I/Q 累加电容。**0/180 样本 = 鉴相推 PI**（波特率 CDR 结构），90/270 样本 = 幅度。位姿在幅度轴；相位读数 = PI 码 + 过零残差，给温度通道。PI 环带宽 <1kHz，锁定后可冻结。
- 载波在 Q 累加器电荷域按周期扣除：**5-bit 电流舵 DAC 镜像 I_ref 的直流**（不可用 I_dac 瞬时值——接收峰值时驱动电流过零），幅度由 code 匹配、相位由 PI 锁定的 φ90/φ270 窗给出；相邻码占空比切换 = 一阶 ΔΣ，累加 100 周期 → 等效 11.6 bit；32 码权重由 ADC 逐码自标；TX/DAC/ADC 共用 Vref 做比率测量，各自独立缓冲隔反冲；复制电流取自电流镜副本，不接触线圈，发射不受影响。
- 共享 7-bit SAR（125MSps）只量化残差，量程 ±1 DAC 步（溢出切 ±4 再捕获）。ENOB ≈ 7 + 0.5·log2N；极限依次：DAC 可标定性 → 抖动质量 → 读数次数 → 前端热噪声（~1e-5）。5-bit DAC 配置可达 1e-3，到不了 1e-5（需 DAC ≥8 位或每读累加 1000 周期）。
- 等价变体：ADC 直采 31.25MSps + DAC 三电平预测阶梯接差分 ADC 负端；功能等价，每通道一个 ADC，功耗 2~3×，抖动需 PI 相位抖动补。
- f0 = 125/16 = 7.8125MHz；驱动用 16 点阶梯正弦（方波 3 次谐波仅压到 2e-3）。
- 功耗量级 19 单元 1kHz：~10mW，谐振驱动 5mW 主导。芯片不可放线圈场内（背面 ≥2~3mm 或牺牲格点）；瓦片间共享参考时钟 + 帧同步。

## 3. 1kHz 帧率的压缩路径
驻留 200→30~50µs（SNR −2~2.6×）；调零变必选；并行接收 61→19 驻留（8 路 ADC）；多速率 w 1kHz/面内 200Hz（现有 2 路 ADC 可做）；三色频分再除 3；8→16MHz。机械带宽提醒：BF-1000 + 22mg 环固有频率 ~600Hz，1kHz 需硬档泡棉。

## 4. 板级原型（现成 5-bit DAC + 7-bit 125MHz ADC + 同源 TX 正弦芯片）
| | A：1 颗 + 现有开关矩阵 | C：7 颗 + 开关矩阵 | B：一线圈一颗 |
|---|---|---|---|
| 驻留/帧 | 61 顺序，12ms | 19，~1ms | 19 或频分 7，≤1ms |
| 开关 | 现有 38 只 | 现有 | **无**，C_off 问题消失 |
| 定位 | 替换 AN9238/AN9767 链，61 组跟踪环状态 | 并行接收增益 | ASIC 板级等价物 |

先做 A 验证五条判据：PI 锁定稳定、残差进量程、ΔΣ 平均有效、DAC 自标收敛、1e-3 分辨率；通过后跳 B。板级验证不了的留给 ASIC：38 通道串扰/地弹、功耗、1e-5 地板、电荷域累加器。

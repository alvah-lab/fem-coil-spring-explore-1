# 验证板阵列规模方案（方案C，供选型）

目标：在"快、省"与"能证明什么"之间选一个验证板规模。三档方案 + 推荐分步路径。所有数据来自 FastHenry 判决。

---

## 0. 核心约束：完整盲反演的计数下限是 19 单元

方案C 的联合反演需要"观测数 ≥ 未知数"（否则数学欠定，任何算法无解）：

| 蜂窝规模 | 单元 | 观测数 | 柔性先验未知数 | 余量 | 盲反演 |
|---|---|---|---|---|---|
| 1 环 | 7 | 19 | 21 | **−2** | ✗ 欠定 |
| **2 环** | **19** | **61** | **57** | **+4** | ✓ 最小可行 |
| 3 环 | 37 | 127 | 111 | +16 | ✓ 富余 |

- 方形阵更差（4 邻接、边少），同单元数下必欠定，不用。
- **但"验证物理"≠"跑盲反演"**：测试时变形是施加的已知量，不需要盲可解。故物理验证可用更小阵列。

---

## 方案一：7 单元（1 环）—— 物理与可分性验证板

**证明**：
- 反射原理（压铜环 → 有源线圈端口阻抗变）
- **单元级 5 自由度可分**（压缩/剪切/倾斜，cond ~2.7）——"单个单元测多维"核心原理
- 交错锚点两高度机理（3 单元下沉，施加共模剪切 vs 共模倾斜看能否区分）
- 开路协议、螺旋+铜环+泡棉工艺一次打通

**不能证明**：完整盲场反演（7 单元欠定）、联动场统计、阵列级 Mz 旋度重建、边界共模模式。

**规模**：7 线圈 + 7 铜环 + 14 开关（力/感各一）。板约 Ø15mm 有效区。
**成本/周期**：约 19 单元的 1/3。
**适用**：先廉价打掉最高风险的物理与工艺。

---

## 方案二：19 单元（2 环）—— 完整系统验证板（当前冻结设计）

**证明**：方案一全部 + 联动场盲反演 + 阵列级 Mz 重建 + 共模统计 + 边界效应。这是"L2 全阵列六维反演"的完整落地。

**规模**：19 线圈 + 19 铜环 + 38 开关。板约 Ø23mm 有效区。
**成本/周期**：基准（1×）。
**适用**：一步到位证明系统级声明；已有完整交接包与投板前判决（通过）。

**关键数据**（真实 PCB 配置，8MHz，AFE 侧 Neumann 校准后）：
- 自感 ~1.34µH，Q≈63@8MHz
- 自观测反射：标称 62nH / 下沉 22nH；边观测反射 1.3~2.8nH（1.3~2.8mV@10mA）
- 六维可分（rank 61/95），交错破简并 65×
- 分辨率：见 §4（依 AFE 噪声模型分档）

---

## 方案三：37 单元（3 环）—— 富余版（一般不需要）

盲反演余量 +16、边界效应小、Mz 重建更稳。仅当要验证大阵列可扩展性/边界处理时才做。成本约 2×，多数情况过度。

---

## 推荐路径：7 → 19 两步走

1. **先 7 单元**去风险：反射物理、单元可分、交错机理、工艺，1/3 成本先打掉最不确定项。
2. **再 19 单元**：前面已确认，19 单元只新增验证"联合盲反演 + Mz"一个系统级项，风险大降。

一步到位 19 单元亦可（判决已通过），只是把物理与系统风险绑在一次投板。分步更稳、返工成本低。

---

## 4. 分辨率（依 AFE 噪声模型，两档）

真实反射比早期单环模型小 ~6×（AFE 侧 Neumann 已校准，比例守恒、判决结论不变）。分辨率取决于 AFE 噪声性质：

| AFE 噪声模型 | w 法向 | 面内差分 | 说明 |
|---|---|---|---|
| 真·1e-3 相对（在真实反射上达到） | ~0.7µm | ~0.9µm | 尺度不变（信号与噪声同比缩小，比值不变），保住亚微米 |
| 固定绝对地板 ~5pH（弱边观测触底） | ~0.9µm | **~3µm** | 自观测反射强(22~62nH，地板不 binding)；边观测弱(1.3~2.8nH)，5pH 地板 = 相对 2~4e-3，退化 ~3× |

**推导**：分辨率 ∝ 噪声/信号。纯 1e-3 相对下二者同比 → 尺度不变，维持 pcb_verdict 的 0.71/0.90µm。绝对地板下，binding 只发生在**弱边观测**：真实边反射 1.3nH，1e-3 相对 = 1.3pH < 5pH 地板 → 边观测有效相对噪声升到 ~3.8e-3 → 面内退化 ~3×。自观测反射 22~62nH（1e-3=22~62pH >> 地板）不受影响，w 保持亚微米。

**设计杠杆（给 AFE）**：唯一决定面内分辨率的是**边观测噪声地板**。能在 1.3nH 边反射上做到 1e-3 相对（≈你们的 1.3µV 目标）→ 面内亚微米；被 ~5pH 地板限 → 面内 ~3µm、法向仍 ~0.9µm。你们按保守值（边观测 1e-3=1.3µV）设计正是对的。

（注：一次缩放版重算脚本有自洽性 bug 已弃用；此表由尺度不变性 + 地板 binding 解析推导，与 pcb_verdict 自洽基线一致。）

（此表 7 单元与 19 单元一致——分辨率是单元级/局部量，不随阵列规模变。）

## 5. 三档速览

| | 7 单元 | 19 单元 | 37 单元 |
|---|---|---|---|
| 成本/周期 | 1/3 | 1× | ~2× |
| 反射物理 | ✓ | ✓ | ✓ |
| 单元 5-DOF 可分 | ✓ | ✓ | ✓ |
| 交错锚点机理 | ✓（演示） | ✓（统计） | ✓ |
| 完整盲反演 | ✗ 欠定 | ✓ 最小 | ✓ 富余 |
| 阵列级 Mz | ✗ | ✓ | ✓ |
| 定位 | 物理去风险 | 系统落地 | 可扩展性 |

**一句话**：省钱快速去风险选 7 单元；一步证明系统选 19 单元；7→19 分步最稳。

---

## 6. 柔性层（各档通用）

单层硅胶泡棉，**开孔**（不再要求闭孔），静息厚 2.38mm (3/32") 对应 2.5mm 静息间距；工作行程 2.5→1.35mm（0~45% 应变，线性区），1.0mm 仅作过载止点。首轮实测用手头 BISCO BF-1000 2.38mm（≈0.4N/单元@25%）；HT-870 / 国产 ZY9090-HS（≈0.6/0.8N/单元）留作换测档位，同厚备 BF-1000 / HT-800 换测三档力程。详见 `柔性层材料选型_BISCO.md`。

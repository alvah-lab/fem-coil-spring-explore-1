# 滑移检测振动通道 Brief（方案C 附加功能，2026-09-07）

前提：读者已知方案C 反射环原理。本文只讲如何从现有扫描链里额外拿出一个宽带振动信号用于滑移检测。**硬件不改，只改固件。**

---

## 1. 目标

在 77Hz 位姿帧之外，并行输出一路带宽 ~10kHz 的表面振动信号，用于检测接触物体相对表面的**滑移起始**（stick-slip 引起的 100Hz~几 kHz 微振动，幅度 1~100µm）。只判"有没有滑"和"什么时候开始滑"，不定位、不测幅值绝对值。

## 2. 原理

反射电感是环-线圈间隙 z 的连续函数，8MHz 载波被 z(t) 调制。相干解调后的带宽只受解调低通限制，与帧率无关。滑移振动是**表面共模**的（整层泡棉带着所有铜环一起抖），任一时刻正在测的那个观测里都含有它，只是灵敏度系数不同 → 按系数归一化后跨驻留拼接，得到连续的振动时间序列。

## 3. 固件改动

| 步骤 | 内容 |
|---|---|
| 解调 | NCO 混频后低通从"整驻留积分"改为 20kHz 截止，按 50kSps 输出 IQ 流（每驻留 10 个点） |
| 去静态 | 每次驻留减去**上一帧位姿正演出的该观测预测值**（不是驻留内均值，那会把 5kHz 以下一起减掉） |
| 归一化 | 残差 ÷ 该观测对共模 w 的 Jacobian 系数（标定时存表，19 自 + 42 边各一个） |
| 拼接 | 按灵敏度加权合成一路序列；驻留切换后前 5µs 样本作废 |
| 陷波 | 驻留周期严格固定 200µs → 切换台阶产生 5k/10k/15kHz 梳齿，固定陷波 |
| 判决 | 带通 100Hz~5kHz → 包络 → 与静态噪底比，超阈值持续 >2ms 报"滑移" |

先只用 19 个自观测驻留（灵敏度最强、占帧 31% 时间），边观测丢弃；够用再加。

## 4. 预期性能

| | v1 链（12bit、10mA、无调零） | v2（30mA、调零+PGA） |
|---|---|---|
| 位移噪声密度 | ~10 nm/√Hz | ~0.5~1 nm/√Hz |
| 100Hz~5kHz 带内 RMS 噪声 | ~0.7 µm | ~50 nm |
| 滑移振动典型幅度 | 1~100 µm | 同 |
| 最小可判滑移幅度（SNR 5） | ~3.5 µm | ~0.3 µm |
| 事件延迟 | ~2ms（包络积分），远早于下一位姿帧（13ms） | 同 |

v1 就够做滑移判决。

## 5. 限制

- **机械带宽**：BF-1000 泡棉 + 22mg 铜环固有频率量级 ~600Hz，强阻尼。接触物直接把振动压在环上时不受此限（位移是强加的）；但泡棉自身的高频传递会衰减，实际有效带宽以上板实测为准。换硬档泡棉（HT-800 / ZY9090-H）约提到 1.2kHz。
- 不是空气声麦克风：1Pa 声压只有 36nm 位移，噪底折合 100~120dB SPL。
- 共模假设：局部滑移只抖动几个单元时，只有那几个自观测驻留能看到，帧内有效采样时间变短，灵敏度按比例下降；检出仍可，只是阈值要放宽。
- 位姿预测误差 1e-3 → 每驻留残留台阶折合 ~14nm，与 v1 噪声同量级，不成瓶颈。

## 6. 验证方法

1. 静置噪底：记录 1s 振动通道，谱上确认 5kHz 梳齿被陷波、带内噪底与表中一致。
2. 已知激励：压电片贴在铜环层上打 500Hz / 2kHz 正弦，幅度 1µm 与 10µm，确认解调幅度线性、相位连续跨驻留。
3. 滑移：砝码压在表面用线拉动，示波器同步记录拉力，看振动通道在力曲线拐点（静摩擦→动摩擦）处的响应延迟。

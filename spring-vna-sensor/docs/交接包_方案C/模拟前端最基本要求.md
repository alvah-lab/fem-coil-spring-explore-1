# 模拟前端（AFE）最基本要求

**这是达成传感目标的最小充分要求。你可以任意优化、换器件、改架构——只要满足下面每条"硬约束"即可。** 硬约束来自电磁判决，违反会导致测不准或测不到；软建议是参考实现，可自由替换。

---

## 0. 系统总目标（决定所有规格）

- 分辨互感/端口电感的**相对变化 1e-3**（判决据此给出亚微米分辨率）
- 19 单元、六维反演；顺序采集帧率 ≥50Hz 即可（验证阶段）

---

## 1. 驱动（1 个 DAC/DDS 通道即可）

| | 要求 |
|---|---|
| **硬约束** | 正弦驱动，频率 5~10MHz 可调，频率稳定；与接收共**同一时钟**（相干检测前提） |
| **硬约束** | 提供**驱动电流参考**（sense 电阻或等效），供归一化与相位基准 |
| 软建议 | DDS（AD9833/9834）或 FPGA DDS；驱动电流 ~10mA（可 3~30mA 调）；输出级驱动 ~1.5µH+1.5Ω 负载 |
| 可选 | 第二 DAC 通道生成调零抵消音（见第 5 节）；无也能先验证 |

**为什么 5~10MHz**：低于铜环自谐振、65M ADC 每周期 6~13 样本、信号 ∝ω 够强。不是硬性,可在此范围调。

---

## 2. 接收（1 个 ADC 通道即可）

| | 要求 |
|---|---|
| **硬约束** | 相干测量幅度**和**相位（IQ 或过零+幅度均可）——只测幅度不够，相位用于分离 jωM 与阻性项 |
| **硬约束** | 接收线圈侧输入阻抗 ≥100kΩ（高阻，不得给线圈加载） |
| **硬约束** | 有效分辨达到 1e-3 相对（下面二选一实现） |
| 软建议 | 12~14bit / ≥40MSps ADC（你手上 65M 双通道够）；缓冲+PGA+带通抗混叠 |

### 达到 1e-3 的两条路线（任选，硬约束是结果不是手段）
- **A. 大动态范围直测**：观测背景大（自观测端口电感是信号的 ~20~50 倍），需 ~14bit ADC + 多档 PGA 覆盖 87dB。简单但费 ADC 位数。
- **B. 调零后低位 ADC**（推荐，见第 5 节）：先抵消已知载波，ADC 只看残差，8~10bit 够（MCU 内置 ADC 可用）。省器件但需抵消 DAC。

**你可自由选 A 或 B。** 验证第一步（L0/L1 用 VNA）两者都不涉及。

---

## 3. 通道选择开关（每线圈一个，最关键的硬约束）

| | 要求 |
|---|---|
| **硬约束（最重要）** | 非活动线圈必须**开路**：断态下线圈回路阻抗 ≥230kΩ @工作频点。注意是**工作频率下的阻抗**，不是直流电阻！ |
| **硬约束** | 普通模拟 mux 断态电容几 pF，在 5~10MHz 只有 kΩ 级 → **不合格**。需低断态电容开关 |
| 软建议 | 每线圈就地 RF/SOI 开关，断态电容 C_off≤0.25pF（10MHz）或≤0.5pF（5MHz）；或两只 SPST 串联降 C_off |
| 软建议 | 一端永久接地、另一端切换（驱动/接收/开路），控制用 SPI 移位寄存器菊花链 |

**违反后果**：50Ω 端接对最弱观测干扰 151%，谐振负载 10⁴%——传感直接失效。这是唯一不可妥协的模拟约束。

---

## 4. ADC/DAC 与 FPGA（你已有：65M ADC 双、125M DAC 双）

| | 要求 |
|---|---|
| **硬约束** | ADC、DAC、FPGA 三者同源时钟（相干） |
| 软建议 | 单通道即可：DAC 一路驱动、ADC 一路接收；电流参考分时采或首帧标定 |
| 软建议 | FPGA 做数字 IQ 下变频（fs/4 架构可免乘法器）+ 累加；反演可 FPGA 内做或回传 PC |
| 可选 | 第二 ADC 通道做同步 V/I 真比值（更准）；第二 DAC 通道做调零音 |

---

## 5. 调零（可选增强，非必须）

- 用途：抵消端口电感的大载波，使残差进 ADC，等效提升有效位数 10~30 倍
- **硬约束（若采用）**：抵消音注入点必须在**高阻缓冲之后**（求和节点），不得注入线圈端子（否则线圈载流、发射、污染其他观测）
- 软建议：DAC 生成幅相可调抵消音，抵消到载波的 <1%；方案C 载波是基座固定几何，抵消值可静态标定+慢漂跟踪
- 验证阶段可先不做（用 VNA 或 14bit 直测）；量产/低成本时再上

---

## 6. 温度（方案C 免费红利，无强制要求）

- 反射虚部（测位姿）对铜环电阻温漂免疫 ~1/Q²；实部可作分布式温度计
- 无需专门温补电路（高 Q 时）；小型化 Q 下降后再考虑用实部补偿

---

## 7. 一句话总结硬约束（共 5 条）

1. 驱动/接收/ADC/DAC **同源时钟**（相干）
2. 测**幅度+相位**（不能只幅度）
3. 达到 **1e-3 相对**分辨（大动态范围直测 或 调零+低位ADC，任选）
4. 接收侧**高阻**（≥100kΩ）不加载线圈
5. **非活动线圈开路**：断态回路阻抗 ≥230kΩ @工作频点（防间接耦合串扰）——**唯一绝对不可妥协项**

其余全部可优化、可换器件、可改架构。

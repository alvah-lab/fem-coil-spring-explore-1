# PCB 验证板交接包 — 蜂窝阵列无源反射式六维力传感器（方案C）

本包用于在另一 session 中完成验证板 PCB 设计。所有电磁参数已由 FastHenry 有限元判决冻结（投板前验算通过）。**模拟前端只给最基本要求，你可自由优化/换器件。**

---

## 0. 一分钟背景

- 传感原理：柔性表面内侧贴**无源单匝短路铜环**（随表面动），PCB 上是**有源螺旋线圈**（固定）。驱动有源线圈，铜环感应涡流反射回来改变线圈端口有效电感 Im(Z)/ω；测多个线圈的端口/互耦阻抗 → 联合反演铜环位姿场 → 表面六维力。
- 关键创新：① 铜环无源无引线（运动层零电路）；② 有源线圈**两种高度交错排布**（破除平移/倾斜共模简并）；③ 非活动线圈必须**开路**。
- 本板目标：L2 全阵列验证——19 单元、六维反演、交错破简并。

## 1. 冻结的 PCB 规格（电磁判决已锁定，勿改）

| 项 | 值 | 依据 |
|---|---|---|
| 板层 | 4 层 | L1+L2 一组线圈、L3+L4 一组线圈 |
| **板厚** | **1.0mm** | 使 L1+L2 与 L3+L4 线圈质心高差 = 0.73mm（破简并 65×） |
| 外层铜厚 | **1oz** | 必须；2oz 会强制线宽变粗、匝数不够 |
| 内层铜厚 | **1oz**（默认 0.5oz 需手动改） | 降线圈电阻、Q 48→更好 |
| 工艺 | 标准 3.5/3.5mil（0.089mm 线宽/线距） | Ø5mm 内绕 12 匝所需 |
| 阵列 | 19 单元蜂窝，pitch 5.2mm | 见 layout.json / 下表 |

### 有源螺旋线圈参数
- 外径 Ø5mm、内径 Ø0.7mm、12 匝/层、双层串联（L1+L2 或 L3+L4，中心过孔连接两层）
- 线宽 0.089mm、线距 0.089mm、匝距 0.178mm
- 目标自感 ~1.5µH（标准工艺）/ Q≈48@10MHz
- **绕向必须两层接续同向**（外→内下过孔→内→外，磁场叠加，勿反向抵消）
- 内端经中心过孔跳层引出

### 交错高度分配（关键！）
- **标称单元（12 个）**：线圈画在 **L1+L2**
- **下沉单元（7 个）**：线圈画在 **L3+L4**（天然低 0.73mm）
- 分配见下表 sunk 列（三色格取一色下沉）

### 层叠（1.0mm 4 层，向 JLC 确认精确 prepreg/core）
```
L1(1oz) ── prepreg ~0.1mm ── L2(1oz) ── core ~0.6mm ── L3(1oz) ── prepreg ~0.1mm ── L4(1oz)
L1+L2 线圈质心 z≈0.08mm，L3+L4 线圈质心 z≈0.81mm，高差 0.73mm
```

## 3. 机械叠层（PCB 之上）

```
┌─ 紫铜环阵列 (19个, 全部同高) ── 贴泡棉顶面
│  紫铜 T2, Ø5mm外/Ø3mm内/0.2mm厚, 闭合环 (网购冲压环)
├─ 硅胶泡棉 1.5~1.8mm 厚 (闭孔, 邵氏00 20~40, 低压缩变形)
└─ PCB 顶面 (L1)
```
- 铜环全部同高（不跟随交错！高差只在 PCB 侧）
- 铜环与对应线圈同轴对齐（xy 与 layout 一致）
- 泡棉厚度对应静息间距（铜环质心到 L1 线圈 ~1.75mm）

## 4. 电磁判决背书（为什么是这些参数，勿改动的理由）

- 真实 PCB 配置 FastHenry 判决：无先验秩 61/95、柔性先验下六维可分、法向分辨率 0.71µm、面内 0.90µm（`pcb_verdict.json`）
- 交错 0.73mm：破简并 65×（同高度锚点则平移/倾斜简并不可解）
- 开路协议：非活动线圈若 50Ω 端接，对最弱观测干扰 151%；必须开路
- 详见 `方案C专利分析Brief.md`、`图表33/34`

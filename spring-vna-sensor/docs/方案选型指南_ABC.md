# 方案选型指南：A（独立双端口）/ B（串联单端口）/ C（无源反射环）

基于 19 单元 FastHenry 判决数据（存档 Jacobian）与解析标度律。所有数字可按标度律换算到其他尺寸/密度。

---

## 0. 一个先于所有对比的关键发现：比较基准决定排名

位姿分辨率 = FoM × 测量噪声。但"测量噪声"有两种物理来源，**三个方案在两种基准下排名相反**：

**基准一：绝对噪声限制**（放大器/热噪声地板，前提是调零抵消背景 + 相干积分）

| µm per nH 噪声 | w 法向 | 面内差分 | 面内共模 |
|---|---|---|---|
| A | 0.96 | 2.3 | 8.1 |
| B | 0.53 | 0.68 | 不可测 |
| **C** | **0.025（38 倍优于 A）** | 6.3 | 7.5 |

C 的法向绝对灵敏度极高——反射观测经"强耦合×强耦合"乘积路径（含 346% 杂化链），单位位移引起的绝对电感变化比 A 的直接互感大一个量级。

**基准二：相对精度限制**（增益稳定性/动态范围，1e-3 of 载波，无调零）

| 1σ 分辨率 (µm) | w 法向 | 面内差分 | 面内共模 |
|---|---|---|---|
| **A** | **1.07** | **1.3** | **1.3** |
| B | 9 | 13 | 不可测 |
| C | 23.6 | ~15 | ~200 |

A 胜出，因为它的观测量背景小（直接互感无载波），1e-3 相对 = 很小的绝对值；C 的反射骑在 2.3µH 载波上，相对基准下吃大亏。

**结论**：AFE 投入（调零/斩波/自校准，把工作点推向绝对噪声限制）本身就是方案选择的一部分。**A = 对 AFE 最宽容；C = 与调零深度绑定，但绑定后法向通道有巨大灵敏度余量**。

## 1. 同等效果的驱动能耗比（绝对噪声基准，含驻留数与线圈电阻差异）

E ∝ 驻留数 × R_drive × FoM²，归一到 A：

| 目标 | A | B | C |
|---|---|---|---|
| 同 w 法向分辨率 | 1 | 0.25 | **~0.0003**（3000 倍省） |
| 同面内分辨率 | 1 | 0.07（仅差分） | 3.1 |

- **法向主导的应用（压力成像），C 是压倒性的功耗冠军**——巨大的灵敏度余量可全部换成驱动电流缩减或积分时间缩短。实际收益会先撞上模型误差/机械振动地板，但方向明确
- 面内主导的应用，A 最省；C 贵 3 倍
- 注意此表与"相对噪声"世界里 B 贵 60 倍的结论不矛盾——是基准不同（B 的观测背景大：5.5µH 端口自感）

## 2. 尺寸与匝数标度律（三方案通用）

设线圈直径 D、匝数 N、阵列 pitch p、频率 f、线径截面 A_w：

| 量 | 标度 | 说明 |
|---|---|---|
| 可分性/条件数 | **尺度不变** | 耦合系数 k 只依赖几何比例——所有判决结论对任意等比缩放成立 |
| 信号 | ∝ f·N²·D·I | |
| 达到目标 SNR 的驱动功率 | **∝ 1/(f²·N³·D·A_w)** | 匝数的三次方红利！ |
| 高密度（全尺寸 ∝p，线径 ∝p）单元功耗 | ∝ 1/(N³·p³) | |
| **单位面积驱动功耗** | **∝ 1/(N³·p⁵)** | 密度的五次方惩罚——用户直觉"密度上去后功耗关键"的定量形式 |
| 单位面积 AFE 功耗（并行读出） | ∝ 1/p² | 温和得多 |

**高密度的三根救命稻草**：① 榨满 N（受自谐振频率和捆束外径限制）；② 提高 f（受就地开关断态电容规格 C_off·f 限制——三方案的底层开关同限）；③ **选 C 的法向大余量**（密度上升信号 ∝p 衰减，C 的 38 倍法向余量就是 38 倍的密度缓冲）。

**匝数/直径的方案差异**：
- A/B：上下都是 N 匝捆束，N 受 SRF 与束径限制（15×0.05mm 束径 0.22mm，D 缩小时 N 被迫降 → 功耗 N³ 惩罚加重）
- C：**顶环永远单匝**（磁通守恒，反射与匝数无关），只有底层吃 N 红利——小型化时顶层零负担，底层与 A 同规则

## 3. AFE 要求对比

| | A | B | C |
|---|---|---|---|
| 端口数/单元 | 2 | 1 | 1 |
| 运动层引线 | 有 | 有 | **无** |
| 就地开关 (C_off≤0.25pF@2.5MHz) | 38 | 19 | 19（仅底层） |
| 观测背景/动态范围 | 87dB，3 档 PGA | 类似+大自感载波 | 2.3µH 载波（34dB 压在信号上） |
| 调零（桥式）| 可选增强 | 可选 | **事实必选**（否则掉入相对基准，性能崩到 24µm） |
| 增益稳定性要求 | 1e-3（宽松） | 1e-3 | 载波抑制后 1e-3；不抵消则需 1e-6（不现实） |
| 温度 | 免疫（M 纯几何） | 免疫 | 1.9e-4/K（免校准） |
| 最小配置 | 1DDS+1ADC 均适用；差异全在上表 | 同 | 同 |

## 4. 算力与反演复杂度

| | A | B | C |
|---|---|---|---|
| 正演模型 | 线性（预存 J） | 二次（0.2mm 邻缘） | 二次+全耦合矩阵（19×19 复数求逆/帧） |
| 反演 | 一步线性，~10 kFLOP/元/帧 | 自感自举+工作点 GN，~80 kFLOP/元/帧 | 双速（54 强方向快 + 3 弱共模慢），~100–200 kFLOP/元/帧 |
| 1000 元 @1kHz 平台 | MCU/树莓派 | 树莓派~Jetson | 树莓派 4~Jetson |
| 标定复杂度 | 低（比值法） | 中 | 中高（背景刚性稳定是前提，好在 B-B 全固定） |

## 5. 决策矩阵

| 场景 | 首选 | 理由 |
|---|---|---|
| 研发/标定平台、最高精度、全六维含共模切向 | **A** | 全可测、线性一步反演、对 AFE 最宽容 |
| 成本极敏感 + 分辨率要求松（~10µm 级） | **B** | 端口减半，AFE 最少；接受共模面内不可测（边界兜底） |
| **长寿命/高弯折次数**（可穿戴、机器人皮肤） | **C** | 运动层零引线——挠曲导线是此类产品头号失效模式 |
| **高密度阵列**（pitch < 3mm） | **C** | 顶层可印刷/冲压、无布线拥堵；38 倍法向余量缓冲 p⁵ 功耗惩罚 |
| 电池供电、法向为主（压力分布成像） | **C** | 同分辨率驱动能耗 ~1/3000（撞地板前） |
| 面内力为主（剪切测量仪） | **A** | C 在面内贵 3 倍且共模慢 |
| 快速原型、最简单软件 | **A** | 线性模型，无双速/自举 |
| AFE 团队弱、无调零能力 | **A** | C 不抵消载波就废，B 动态范围也难 |

**一句话版**：精度和省事选 A，省钱选 B，**量产/密度/寿命/功耗选 C（但必须做好调零和全耦合模型）**。

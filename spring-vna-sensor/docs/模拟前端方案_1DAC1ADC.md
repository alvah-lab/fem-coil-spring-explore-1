# 模拟前端建议方案：1 DAC + 1 ADC 最小配置

适用：蜂窝阵列六维力传感器（方案 A：19 单元 38 线圈 / 方案 B：19 线圈），顺序采集。
所有数值可直接按比例换算到其他阵列规模。

---

## 0. 系统级选择（先定三个数）

| 参数 | 取值 | 理由 |
|---|---|---|
| 工作频点 f0 | **2.5 MHz** | 容性泄漏干扰 ∝f²，从 10MHz 降到 2.5MHz 把断态开关要求放松 16 倍；SNR 余量仍大（见 §4） |
| ADC 采样率 fs | **10 MSps = 4×f0** | fs/4 架构：数字混频序列为 ±1,0，**无乘法器**，MCU/小FPGA 即可 |
| 驱动电流 | 10 mA（可升至 30mA 买余量） | 线圈 R≈2Ω，功耗 mW 级 |

时钟约束：DDS 与 ADC 必须同源时钟（相干检测的前提）。

---

## 1. 总体框图

```
                 ┌──────────── 驱动总线 ────────────┐
 DDS/DAC ─ LPF ─ 功放 ─ Rs(电流sense) ┤             │
                        │             │  每线圈: 一端固定接地,
                        │(sense点)    │  另一端经 SP3T 就地开关:
                        │             │   [驱动总线 | 接收总线 | 开路]
                 ┌──────┴─── 接收总线 ┤             │
                 │                    └─────────────┘
 ADC ← 抗混叠BPF ← PGA ← 高阻缓冲 ←──┘
  ↑ (ADC 输入前 2:1 开关: 接收链 / 电流sense)
 MCU/FPGA: DDS相位、fs/4 DDC(I/Q 累加)、开关控制(SPI菊花链)、反演
```

**关键简化：每线圈一端永久接地**。开路态=热端悬空，回路自然断开；
驱动/接收都只需切热端 → 每线圈仅 1 个 SP3T，开关数 = 线圈数。

## 2. 各模块需求规格

### 2.1 驱动链（唯一 DAC）
| 项 | 规格 | 备注 |
|---|---|---|
| 波形 | 2.5MHz 单频正弦，幅相稳定 | DDS 芯片(AD9833/9834)、MCU定时器+滤波、或FPGA DDS 均可 |
| 谐波 | 3次谐波 < −50dBc（滤波后） | **fs/4 采样时 3f0=7.5MHz 会混叠回 f0！** 靠驱动 LPF + 接收 BPF 双重压制 |
| 输出级 | 运放/推挽，负载≈2Ω+j36Ω(2.5MHz) | 10mA 满摆幅 ~0.4Vp，普通高速运放即可 |
| 电流 sense | 串联 Rs=10Ω 差分取样 | 送 ADC 分时测量，作幅度与相位基准 |

### 2.2 接收链（唯一 ADC 前端）
| 项 | 规格 | 备注 |
|---|---|---|
| 缓冲 | 输入 ≥100kΩ ‖ ≤3pF，就近总线 | JFET/CMOS 运放；输入C是可标定增益因子(顺序模式) |
| PGA | 3 档：0 / 20 / 40 dB | 信号动态范围 87dB(276mV~3.2µV@2.5MHz)超过单档ADC；每个观测的量级已知，按查表预设档位 |
| 抗混叠 BPF | 中心 2.5MHz，带宽 ~1MHz，7.5MHz 处 ≥40dB | LC 二阶+RC 即可；与驱动 LPF 合计压制混叠谐波 ≥90dB |
| ADC | **12–14 bit，10 MSps**，单通道 | 例: AD9235/内置于部分MCU的高速ADC不够，选外置流水线/快速SAR，$3–8 |
| ADC 输入开关 | 2:1（接收链/电流sense） | 普通模拟开关即可（此处不接线圈，无 C_off 顾虑） |

### 2.3 线圈就地开关（本方案唯一的特殊器件）
| 项 | 规格 | 备注 |
|---|---|---|
| 类型 | SP3T（或两只SPDT）RF/SOI 开关 | 例: PE42422 类、BGS12/BGS14 类 |
| **断态电容 C_off** | **≤ 0.25 pF** | 2.5MHz 下 \|Z\|≥255kΩ → 第三线圈干扰 ≤0.09%（判据 ≥230kΩ）|
| 导通电阻 | ≤ 2Ω | 与线圈 2Ω 同量级，进入标定 |
| 切换时间 | ≤ 1µs | 影响驻留开销 |
| 控制 | SPI 菊花链移位寄存器，38 位 | 2 根控制线扫全阵列 |

若选不到 0.25pF 的单开关：两只串联（C 减半）或把 f0 再降到 1.25MHz（要求放松到 0.5pF）。

### 2.4 数字部分（MCU 或小 FPGA 二选一）
| 任务 | 负载 | 平台 |
|---|---|---|
| fs/4 DDC：±1,0 混频 + 累加 | 10MSps × 每样本2次加法 = 20Mops | STM32H7 用定时器+DMA+SIMD 可扛；iCE40/Gowin 更从容 |
| 每驻留输出 | 一对 (I,Q) 32bit 累加值 | |
| 反演 | 0.2 MFLOP/帧 × 250Hz = 0.05 GFLOPS | H7 的 FPU 富余 10 倍 |
| 帧调度/开关控制/标定 | 轻 | |

**推荐单片方案：STM32H723（≥550MHz，内含≥2个3.6MSps ADC不够用，仍需外置ADC）或
带硬核ADC接口的小FPGA+Cortex-M。最省事组合：小FPGA(DDC+时序) + 任意MCU(反演+通信)。**

## 3. 时序与帧率预算（方案 A，19 单元）

| 项 | 时间 |
|---|---|
| 每驻留：开关切换+建立 | 3 µs |
| 每驻留：IQ 积分 | 20 µs |
| 观测数/帧（去互易重复） | 145 |
| 电流参考+PGA校准驻留 | ~8 次/帧 |
| **帧时间** | **≈ 3.5 ms → 280 Hz** |

方案 B（61 观测）：≈1.6ms → **620 Hz**。
不够快时的第一杠杆：并联第 2 条接收链（+1 ADC → 帧率×2，架构不变）。

## 4. 信噪比核算（最弱观测，2.5MHz / 10mA）

```
最弱互感(邻居斜对TB): 20nH → V = ωMI = 3.2 µV??  ← 束绕值 0.02µH: V=3.14mV
  修正: 0.02µH×2π×2.5MHz×10mA = 3.14 mV
1e-3 精度需分辨 3.1 µV
噪声底 ~2nV/√Hz, 20µs积分(等效带宽25kHz) → σ ≈ 0.32 µV
→ 余量 ~10 倍 ✓ (不足时提驱动电流或加长积分)
```

## 5. 标定策略

1. **通道幅相标定**：每帧插入"驱动总线直连接收链"参考驻留 → 消除 DDS/功放/PGA/ADC 全链漂移；
2. **电流基准**：每帧 1 次 ADC 切到 sense 采驱动电流幅相；
3. **温度**：IQ 同相分量（耦合电阻）随温度变化，作为免费温度计参与补偿；
4. **几何标定**：M(位姿) 代理模型出厂标定（位移台扫描或 FastHenry 模型+少点修正）。

## 7. 扩展路径（架构不推倒）

| 需求 | 改动 |
|---|---|
| 帧率×2~4 | 加 1–3 条接收链（PGA+ADC），mux 加接收总线 |
| 帧率与阵列规模无关 | 三色频分：DDS 增至 3 个频点、每单元接收链，数字 DDC 3 路 |
| 大阵列(>100单元) | 总线分区（每 19 单元一段总线+段开关），控制链级联 |
| 极限功耗 | 本文档拓扑可直接映射到 130nm ASIC（见算力/功耗评估） |
```

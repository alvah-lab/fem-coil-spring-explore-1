# K18 标定拼图件（六边形垫片 + 19 格外框）

生成：`/work/alvah-labs/spiral-coil/coil-5/.venv/bin/python3 scripts/calib_fixture_cad.py`（CadQuery 2.7），输出本目录 STEP/STL；`view_*.png` 为检查视图（片轴测/剖面/底面刻字、19 片拼合、外框顶/底、外框+片+板装配）。

## 六边形片（tile）

- 对边 5.05 mm（间距 5.2 − 2×0.075 配合间隙），外接圆 Ø5.83，平边法向指向相邻单元，实心六棱柱。
- 顶面开环形凹槽 Ø5.06/Ø2.94、深 0.2，放 Ø5.0/Ø3.0×0.2 铜环（环在片顶，片底贴 PCB 阻焊面）。凹槽外径比对边大 0.005，六个平边处几乎不破边。
- **间隙定义**：环质心 → L1 铜面 = 片高 H + 环半厚 0.1 + 阻焊 0.03，即 **H = gap − 0.13**。
- 倾斜片：顶面绕片心倾斜 θ，环质心仍在片心正上方 gap 处；高侧平边上有一个 V 形缺口标方向（方位 φ 从 +x 逆时针）。
- 偏移片：凹槽中心偏移 dx（面内可观测性）。
- 底面刻字 `gap[/θ][/xdx]`，空白片（无槽）加 `B`。从底部看字是正向的。

| 文件 | gap (mm) | θ | 备注 |
|---|---|---|---|
| tile_g1 / g1p35 / g1p75 / g2 / g2p53 | 1.0 / 1.35 / 1.75 / 2.0 / 2.53 | 0 | 行程下限 / 45% 压缩 / 判决点 / 中间 / 静息 |
| tile_g1p75_t2d0, tile_g1p75_t5d0 | 1.75 | 2°, 5°（方位 0°） | 倾斜可观测性 |
| tile_g1p75_x0p5 | 1.75 | 0 | 凹槽偏移 +0.5 mm（x） |
| tile_g1p75_blank | — | — | 无槽空白片，填位用 |
| assembly_tiles.step | — | — | 19 片拼合示意（中心 5° 片 + 邻居各高度） |

其它 gap/θ/φ/dx 组合改脚本里的 `GAPS/TILTS/OFFSETS` 或直接调用 `tile(gap, tilt_deg, tilt_dir_deg, dx, dy)`。

## 外框（frame_19）

- 19 格蜂窝外轮廓（片外接圆 + 0.075 间隙）向外 3.0 mm 的一圈围墙，厚 2.0 mm，外廓 33.4 × 31.1 mm；+x 侧外壁有一个三角凸起标方向（主机 +x = 板上 L19 / U18N 方向）。
- 定位：6 根 Ø2.0 × 1.3 mm 定位销（端部 0.3 mm 倒角）从框底伸入 K18 的 HLOC1–6 Ø2.2 尼龙孔（板厚 1.0）。孔心到格子边界只有 1.1–1.7 mm，做不了螺钉凸台，所以用销；销与孔单边间隙 0.1 mm，横向定位 ±0.1 mm。
- 周边元件（0402 电容、HMC544A）包络边缘都在阵列中心 19.6 mm 以外，围墙外径 16.3 mm，不压任何元件；不用净空槽。
- 片直接站在 PCB 阻焊面上，外框只管横向定位，其厚度/贴合不进入间隙公差链。
- 待回板核对：线圈的两个 Ø0.45/钻 0.3 过孔焊盘在每个格子的 −30° / 150° 顶点处（相对线圈中心 (±2.51, ∓1.45)），若焊盘凸出阻焊面 >0.05 mm，需在片的六个角开 Ø1.2 让位（脚本里加一个圆柱切除即可）。

## 打印与使用

- 建议光固化（±0.05 mm）；FDM 的 ±0.1–0.2 对 10 µm 级位移分辨率太粗。片高每片打印后用千分尺实测、记在片上，标定表填实测值（GUI 垫片标定页"间隙"填 实测 H + 0.13）。
- 铜环用少量胶固定在凹槽里（或仅放置），环必须与凹槽底贴平。
- 一次只需要放要测的片，其余位置空着或放空白片；外框只卡定位孔，不用拧紧。
- 三色分类（`geometry.COLOR`：0 = 7 个下沉单元 {1,3,6,9,12,15,17}，1/2 = 各 6 个标称单元）可作为"同色不相邻"的放置策略。

# K18 标定整板（N = 8，一体 SLA 打印，转位复用）

生成：`/work/alvah-labs/spiral-coil/coil-5/.venv/bin/python3 scripts/calib_plates_cad.py`（CadQuery 2.7）。每块板 = 19 格实心蜂窝 + 3.5 mm 围框 + 12 个定位通孔 + 板号，34.0 × 32.1 mm；每块板配一块同外形、同孔位的**压板** `clamp_<板号>`（顶面刻 C+板号）。`plates.json` 是布局表（每格 gap/倾角/方位/偏移/环座高度）和转位映射，供主机 GUI 整板模式与数字孪生使用。`sheet_8_plates.png` / `sheet_8_clamps.png` 为 8 块板与 8 块压板的轴测总览；`view_<板>_section_u<单元>.png` 为板 + 铜环 + 压板的装配剖面（A2C 偏移格、A1C 倾斜格、B1 低环座、E1 阶梯、D 阶差对；`view_A1C_section_hole.png` 过定位孔）。`compare_A0/` 是三种倒角做法的 A0 对比（最终采用方案 3 + 2）。

## 几何
- 有环格：顶面在 H = gap − 0.13 mm（环底面；环质心 → L1 铜面 = gap），中心 Ø2.94 × 0.2 凸柱卡住 Ø5.0/Ø3.0 × 0.2 铜环内孔，凸柱上方是一个完整的扁圆锥（母线与水平面 30°，高 0.85 mm，收到尖），环沿锥面滑下自动对中。倾斜格顶面绕格心倾斜、凸柱沿法向；偏移格凸柱偏移。
- 无环格：实心平台，与围框齐平 2.0 mm，无凸柱（v1 是 0.8；抬平后台阶只出现在有环格周围，A0 是一块平板）。板底整面贴 PCB 阻焊面。
- 台阶倒角：每个等高区域的每一圈台阶边界做一条等宽 45° 带，拐角按角平分面斜接。高侧切顶角；低侧是平台时同时加根部（两侧各 Δz/2，B3/E1/D 的 2.4/2.53 格与平台之间成为连续 45° 坡）；低侧是有环格时只切高侧（≤Δz）。带宽上限 0.4（有环格环座保平到 r ≥ 2.2，平台顶角不进定位孔锥口），每圈取最小值使斜接精确；倾斜格的坑从倾斜面脚线起坡到顶。板上没有任何朝下的面，在打印位姿下不需要支撑。
- 环余隙：每个有环格在环座平面以上挖一圈 Ø5.4（环 Ø5.0 + 0.2 余隙）的环形区域，穿过更高的邻格和围框；偏移 0.5 mm 的环（A2C 外圈三格）和贴近围框的环（B1/B2）都放得进去。v1 缺这一刀，A2C 偏移格环放不进去。
- 定位孔：Ø2.2 直段只占中间 20% 厚度，两面各 40% 厚度是 Ø2.5 → Ø2.2 的锥口（板：锥深 0.8，直段 0.4；压板：从围框脚底面到顶面共 4.4，锥深 1.76，直段 0.88）。锥口离围框内沿 0.53 mm，平台顶倒角 ≤ 0.4 不会切进去。
- 板号刻在 +x 侧三角方向标旁的围框顶面（竖排，两孔之间，避开 12 个定位孔）；三角凸起 = 取向 k = 0（指向板上 L19 / 单元 18 方向）。压板顶面同一位置刻 C+板号。

## 定位与转位
- 板背面从 **HLOC2 (60.02, 27.08)** 和 **HLOC5 (59.47, 52.57)** 两个 Ø2.2 孔穿出两颗 M2 螺钉作定位柱（其余四孔不用）。
- 板上 12 个 Ø2.15 通孔是这两点各自 6 个 60° 转位像（相互 ≥ 4.5 mm，离最近线圈中心 ≥ 4.4 mm）。板逆时针转 60k°（k = 0..5）都能套住两颗螺钉。
- 取向 k 下板格 u 落在板上单元 `plates.json["_rotation_maps"][k][u]`。三色类 0 转位不变，类 1 ↔ 类 2 互换。

## 压板（clamp_<板号>）
- 与板互补：同外形，同 12 孔（M2 螺钉穿过板再穿过压板，顶上加 M2 螺母拧紧）。板体厚 4.0 mm，体底面离最高环顶/围框顶 0.5 mm。
- 每个有环格一个实心 Ø4.4 圆柱压脚，端面落在环顶面（环座 + 0.2），端面中心是与凸柱锥互补的 30° 锥形凹（面上 Ø3.5、深 1.01；凸柱锥 Ø2.94 高 0.85，径向余隙 0.28、顶余隙 0.16），环形接触面 Ø3.5–Ø4.4 压在环上（环 Ø3.0–Ø5.0；外径收到 4.4 与倒角后环座 r ≥ 2.2 的平面对应）。倾斜格压脚和锥凹同样倾斜、偏移格同样偏移。没有薄壁。
- 围框脚只落在围框外侧 2.9 mm（内侧留 0.6 避开根部倒角带），比围框顶高 0.1 mm：拧紧时先由压脚把每个环和它下面的格压到 PCB 上，压板再弯 0.1 才顶到围框，围框脚只是止挡。A0 无环，围框脚直接压围框。
- 装配：板套在两颗 M2 螺钉上 → 放环（顺锥面滑到底）→ 压板按同一方向标套上 → 螺母拧紧。换取向时板和压板一起转 60°。螺钉露出板背面 ≥ 12 mm（PCB 1.0 + 板 2.0 + 压板体顶 6.5–7.1 + 螺母）。

## 打印（SLA / MSLA）
- **板：平放，板底直接贴平台，不加支撑。** 板底是整面平面，这样所有环座、凸柱、锥尖、围框顶都朝上，没有任何悬空面，12 个孔竖直（正圆），台阶都是向上的台阶，不需要倒角。v1 立着打印出现的孔顶拱形下沉和内部台阶（E1 最内圈）下沉都是悬空造成的，平放后不存在。
- **压板：顶面贴平台，压脚朝上，不加支撑。** 压脚是向上的实心柱子，锥形凹是向上张开的漏斗面，围框脚是竖壁。用脚本核对过 16 个件在打印位姿下没有朝下超过 45° 的面（只有压板顶面刻字槽的槽底，0.5 mm 高、槽宽 0.4 mm，SLA 可直接跨过）。
- 层高 0.02 mm：环座 1.22 / 1.62 / 2.40、围框 2.0、平台 0.8、环顶 +0.2、锥高 0.85 都是整数层；0.05 mm 层高会把 1.22 圆成 1.20/1.25。
- 首层贴平台会过曝（大象脚、首几层偏厚）：孔口已倒角；高度方向的首层偏厚对所有格子是同一个偏移，用千分尺量围框/平台（2.0）和 B2 环座（1.62）或 B3 环座（2.40）反推 z 偏移和比例，记到 `plates_K18.json` 的 `H_seat_mm`。不要打磨板底。
- Clear V2 韧性大、平放打印的整面粘附也更好，比立着打印不易翘；打印完先在平台上二次固化再取下更平。

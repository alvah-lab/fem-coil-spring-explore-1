# K18 标定整板（N = 8，一体 SLA 打印，转位复用）

生成：`/work/alvah-labs/spiral-coil/coil-5/.venv/bin/python3 scripts/calib_plates_cad.py`（CadQuery 2.7）。每块板 = 19 格实心蜂窝 + 3.5 mm 围框 + 12 个定位通孔 + 板号 + 2 个外伸测量耳，39.6 × 32.1 mm。`plates.json` 是布局表（每格 gap/倾角/方位/偏移/环座高度）和转位映射，供主机 GUI 整板模式与数字孪生使用。`sheet_8_plates.png` 为 8 块板的轴测总览。

## 几何
- 有环格：顶面在 H = gap − 0.13 mm（环底面；环质心 → L1 铜面 = gap），中心 Ø2.94 × 0.2 凸柱卡住 Ø5.0/Ø3.0 × 0.2 铜环内孔，凸柱上方再有 0.2 高、半角 30° 的圆锥导入（顶径 Ø2.71），环套上去自动对中。倾斜格顶面绕格心倾斜、凸柱沿法向；偏移格凸柱偏移。
- 无环格：实心低平台 0.8 mm，无凸柱。板底整面贴 PCB 阻焊面。
- 测量耳：围框 ±x 外壁向外伸出的 3.6 × 3 mm 小耳，高度 = 该板环座最低（−x）/ 最高（+x）H，上下面都外露，千分尺直接量作整板高度基准；`plates.json` 的 `H_seat_mm` 是设计值。
- 板号刻在 −y 侧围框顶面；+x 侧三角凸起 = 取向 k = 0（指向板上 L19 / 单元 18 方向）。

## 定位与转位
- 板背面从 **HLOC2 (60.02, 27.08)** 和 **HLOC5 (59.47, 52.57)** 两个 Ø2.2 孔穿出两颗 M2 螺钉作定位柱（其余四孔不用）。
- 板上 12 个 Ø2.15 通孔是这两点各自 6 个 60° 转位像（相互 ≥ 4.5 mm，离最近线圈中心 ≥ 4.4 mm）。板逆时针转 60k°（k = 0..5）都能套住两颗螺钉。
- 取向 k 下板格 u 落在板上单元 `plates.json["_rotation_maps"][k][u]`。三色类 0 转位不变，类 1 ↔ 类 2 互换。

## 打印
- SLA，以一个侧沿做支撑，只打磨支撑面；不要打磨板底（改变所有间隙）。
- 打印后用千分尺量两个测量座高度和板厚，记入 `plates.json` 对应板的实测值（GUI 整板模式读取）。

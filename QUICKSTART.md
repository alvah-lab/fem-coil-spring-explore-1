## Run Your First Simulation

### Option 1: Use Pre-Generated Test Cases

```bash
python3 tools/run_fh.py examples/test_single_coil.inp
```

Output:
- Zc.mat (impedance matrix)
- Console printout with L, M, k values at each frequency

### Option 2: Generate Custom Coil

```python
from tools.coilgen import gen_single_coil
from tools.run_fh import FastHenryRunner

# Generate 5-turn coil, 10mm radius
gen_single_coil("mycoil.inp", radius=10, num_turns=5, pitch=2)

# Run simulation
runner = FastHenryRunner()
runner.run("mycoil.inp")

# Extract results
freq, Z = runner.load_zc_matrix()
result = runner.extract_inductance(freq, Z)
print(result['inductance_uh'])  # Inductance at each frequency
```

### Option 3: Dual Coaxial Coils (Mutual Inductance)

```python
from tools.coilgen import gen_dual_coil

# Two coaxial coils with 2mm gap
gen_dual_coil("mycoils.inp", radius1=8, radius2=5, gap=2)

# Run and extract
runner.run("mycoils.inp")
freq, Z = runner.load_zc_matrix()
result = runner.extract_inductance(freq, Z)

print(f"Coil 1: L = {result['inductance_uh']['L0'][-1]:.3f} µH")
print(f"Coil 2: L = {result['inductance_uh']['L1'][-1]:.3f} µH")
print(f"Mutual: M = {result['inductance_uh']['L01'][-1]:.3f} µH")
print(f"Coupling: k = {result['coupling_factor'][-1]:.3f}")
```

## Common Tasks

### Change Coil Dimensions

```python
gen_single_coil(
    "mycoil.inp",
    radius=5.0,        # mm
    pitch=1.0,         # mm per turn
    num_turns=20,      # number of turns
    segs_per_turn=12,  # segments per turn (more = finer mesh)
    wire_radius=0.3    # mm
)
```

### Sweep a Parameter

```python
from tools.coilgen import gen_single_coil
from tools.run_fh import FastHenryRunner
import numpy as np

L_results = []
radii = np.linspace(2, 10, 10)

for r in radii:
    gen_single_coil(f"coil_r{r}.inp", radius=r)
    runner = FastHenryRunner()
    runner.run(f"coil_r{r}.inp")
    freq, Z = runner.load_zc_matrix()
    result = runner.extract_inductance(freq, Z)
    L_results.append(result['inductance_uh']['L0'][-1])

# Plot L vs radius
import matplotlib.pyplot as plt
plt.plot(radii, L_results, 'o-')
plt.xlabel('Coil Radius (mm)')
plt.ylabel('Inductance (µH)')
plt.show()
```

### Extract Impedance at Specific Frequency

```python
freq, Z = runner.load_zc_matrix()
idx = np.argmin(np.abs(freq - 1e6))  # Find index closest to 1 MHz
Z_1MHz = Z[idx]
print(f"Impedance at 1 MHz: {Z_1MHz}")
```

## Troubleshooting

### FastHenry won't run
```bash
# Check executable exists and is executable
ls -la FastHenry2/bin/fasthenry
# Run it directly
./FastHenry2/bin/fasthenry examples/test_straight_wire.inp
```

### Python module import error
```bash
# Ensure venv is activated
source venv/bin/activate
# Check numpy is installed
python3 -c "import numpy; print(numpy.__version__)"
```

### Zc.mat parsing fails
```bash
# Check if Zc.mat was generated by FastHenry
head -20 Zc.mat
# Should start with "Row N: ... to ..."
```

### Simulation is slow
- Reduce `segs_per_turn` in coilgen (coarser mesh, faster)
- Reduce number of frequency points in .freq line
- For large geometries, use coarser grid (increase segment length)
